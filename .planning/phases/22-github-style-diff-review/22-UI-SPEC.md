# Phase 22 — UI Design Contract

> Visual and interaction contract for the GitHub-style diff review. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase extends an existing surface.** The diff tab already ships as a single-scroll totals bar + collapsible unified diffs (`web/src/components/task/DiffTab.tsx`, `DiffFileSection.tsx`, `web/src/api/diffs.ts`). This contract builds the GitHub "Files changed" model **on top of the established design system** — it does not introduce a new visual language. All chrome stays neutral zinc; the colored ± diff lines remain the loudest thing on the page (the existing scoped diff-content palette).

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (already initialized — `web/components.json`) |
| Preset | style `radix-nova`, baseColor `neutral`, `cssVariables: true`, no prefix |
| Component library | radix-ui `1.5.0` (primitives copied into `@/components/ui`) |
| Icon library | lucide-react `1.17.0` |
| Font (UI) | `ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif` (`--font-sans`) |
| Font (code/diff/paths) | `ui-mono, "SF Mono", "Cascadia Mono", Menlo, Consolas, monospace` (`--font-mono`) |
| Theme | Dark-only — `class="dark"` hardcoded on `<html>`; zinc ramp via oklch CSS vars |

**Existing primitives reused (no new import):** `collapsible`, `button`, `tooltip`, `label`, `separator`.

**New shadcn primitive required:** `checkbox` (shadcn official) — the "Viewed" control. There is a `switch` primitive present but GitHub's "Viewed" affordance is a checkbox, not a toggle; use `npx shadcn add checkbox`. No `scroll-area` needed — the existing code uses native `overflow-y-auto`; keep that pattern.

## Spacing Scale

Declared values (multiples of 4; matches the compact spacing already used across the task view / diff tab):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | `gap-1` chevron↔label; tree row vertical padding (`py-1`) |
| sm | 8px | `gap-2` between stacked file sections; tree row horizontal padding (`px-2`); totals-bar vertical padding (`py-2`) |
| row-x | 12px | `px-3` file-header + totals-bar horizontal padding (established diff row padding — multiple of 4) |
| md | 16px | `p-4` diff scroll-container padding; content gutter |
| lg | 24px | `gap-6` tab-strip → content gap (from `TaskTabs`) |

Exceptions: none. This surface is a dense code-review tool — no touch-target minimum applies (desktop localhost). Do NOT introduce 32/48/64px layout gaps here; the diff surface is intentionally compact.

**Left file-tree pane width:** `w-72` (288px), fixed. Not resizable in this phase (a resizable splitter is out of scope / a future enhancement).

## Typography

The diff surface is compact and uses exactly **2 sizes** and **2 weights** — the established scale. No display/heading tier exists on this surface (the totals-bar line at 14px is the largest text); do not invent one.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body / UI | 14px (`text-sm`) | 400 regular | 1.5 | sans | Totals-bar summary, tree directory labels |
| Path / filename | 14px (`text-sm`) | 400 regular | 1.5 | mono | File-header path, tree leaf filenames (truncate) |
| Label / stats | 12px (`text-xs`) | 500 medium | ~1.33 | sans, `tabular-nums` | `+add −del` counts, "Viewed" label, status suffix ("new"/"deleted") |
| Code (diff line) | 12px (`text-xs`) | 400 regular | 1.5 (`leading-normal`) | mono, `whitespace-pre` | Hunk headers + add/del/context lines |

Weights declared: **regular 400** + **medium 500** (stats/labels only). No semibold on this surface.

## Color

Dark-only zinc ramp. Values are the existing CSS custom properties (oklch); hex annotations are approximate zinc equivalents.

| Role | Token / Value | Usage |
|------|---------------|-------|
| Dominant (60%) | `background` — oklch(0.141) ≈ zinc-950 `#09090b` | Task-view background, left tree-pane background, diff-content background (`bg-zinc-950`) |
| Secondary (30%) | `card` — oklch(0.21) ≈ zinc-900 `#18181b` | File-header rows, hunk-header rows; `accent`/`muted` oklch(0.274) ≈ zinc-800 `#27272a` for tree-row hover + selected |
| Accent (10%) | `blue-500` `#3b82f6` | See reserved list below |
| Destructive | `destructive` — oklch(0.704 0.191) red | **Not used this phase** — read-only review has no destructive action |

**Accent (`blue-500`) reserved for — explicit list, nothing else:**
1. Active tab underline (`data-active:after:bg-blue-500`) — existing, unchanged.
2. `focus-visible:ring-blue-500` keyboard-focus ring on the file-header trigger, tree rows, and the Viewed checkbox — existing pattern.
3. The **currently-selected file-tree row** — 2px left border in `blue-500` (marks which file the right pane is scrolled to).
4. The **checked "Viewed" checkbox** fill/check — the phase's one new accent use.

**Scoped diff-content semantics (content colors, NOT the accent — never bleed into app chrome):**
- Additions: text `text-green-400` `#4ade80`, line background `bg-green-500/10`.
- Deletions: text `text-red-400` `#f87171`, line background `bg-red-500/10`.
- Context lines / hunk headers / gutter: `text-zinc-400` (`muted-foreground`).

**"Viewed" de-emphasis (status, not accent):** a viewed file dims its path + stats to `muted-foreground` (zinc-400/500); the passive tree check glyph is `muted-foreground` (quiet). Only the interactive header checkbox uses `blue-500` when checked.

## Layout & Interaction Contract

This is the substance of Phase 22. The single-scroll `DiffTab` becomes a two-pane layout; the file section gains a persistent Viewed control.

### Two-pane layout (DIFF-01)
- **Left pane — file tree.** `w-72` (288px), `border-r border-border`, `overflow-y-auto`, full tab height, background = `background`. A directory tree of all changed files (nested folders collapsible; single-child folders may be path-compressed like GitHub, e.g. `internal/api`). A tree-toggle icon button (lucide `PanelLeft`, `variant="ghost" size="icon-sm"`) in the totals bar hides/shows the pane; aria-label toggles `"Hide file tree"` / `"Show file tree"`.
- **Right pane — diff column.** `flex-1`, the existing `overflow-y-auto p-4` scroll container: sticky totals bar on top, then the stacked `DiffFileSection`s (unchanged internals).

### File-tree rows (DIFF-01)
- **Directory row:** folder chevron (lucide `ChevronRight`, rotates on open) + `text-sm` sans label (`muted-foreground`), `px-2 py-1`, clickable to collapse/expand the subtree.
- **File leaf row:** min-height 28px, `px-2 py-1`, `gap-2`; `font-mono text-sm truncate` filename + trailing `+add −del` mini-counts (`text-xs tabular-nums`, green/red). A per-file status glyph is optional; the ± counts carry status.
- **Row states:**
  - default — `text-foreground` (leaf) / `muted-foreground` (dir)
  - hover — `hover:bg-[#27272a]` (zinc-800 — the established hover literal used in `DiffFileSection`/`TaskTabs`)
  - selected — `bg-accent` + 2px `blue-500` left border (the file the right pane is currently scrolled to / last clicked)
  - viewed — filename + counts dim to `muted-foreground`, a small `Check` glyph (lucide, `size-3`, `muted-foreground`) precedes the counts
- **Click behavior:** selecting a tree row **scrolls the right pane** so that file's header sits at the top under the sticky totals bar (smooth scroll; honor `prefers-reduced-motion`). It does **not** change the file's collapse or viewed state (scroll-only; deterministic — see Decisions).

### Per-file collapse/expand (DIFF-02)
- Unchanged from today: the file-header row is a Radix `CollapsibleTrigger`; the `ChevronRight` rotates 90° when open. Collapse and Viewed are **independent** — you can collapse a file without marking it viewed.
- The file-header row becomes **sticky** within the diff scroll container (`sticky` with a `top` offset equal to the totals-bar height) so the Viewed checkbox stays reachable while scrolling a long file (matches GitHub).

### "Viewed" control (DIFF-03)
- A `checkbox` + `text-xs` `muted-foreground` "Viewed" label sits at the **far right of the file-header row**, after the ± stats: `[chevron] [path (flex-1 truncate)] [status] [+add −del] [☐ Viewed]`.
- **HTML-structure constraint:** the checkbox must NOT be nested inside the `CollapsibleTrigger` `<button>` (button-in-button is invalid — same rule the `TaskTabs` × close obeys). Restructure the header as a flex row: `CollapsibleTrigger` takes `flex-1` (chevron + path + stats); the Viewed checkbox is a **sibling** element. The checkbox `stopPropagation`s so toggling Viewed does not also fire the collapse trigger.
- **Marking Viewed → collapses that file** (explicit, per DIFF-03) and dims the header (path + stats → `muted-foreground`). Unchecking Viewed **re-expands** the file and restores full contrast.
- Checkbox aria-label: `"Mark {filename} as viewed"` / `"Mark {filename} as not viewed"`.
- Persistence is server-side (per STATE plan note: a new table keyed by task + file path + content hash) — the checkbox reflects that persisted state on every open, including after a server restart.

### Auto-reset on change (DIFF-04)
- Purely a rendered outcome of server state: on open, a previously-viewed file whose content changed comes back **un-viewed (checkbox empty) and expanded**; its tree row returns to full contrast (no check glyph). Unchanged viewed files stay checked + collapsed + dimmed.
- **No "changed since viewed" badge or diff-of-diffs indicator** — that is DIFF-FUT-03 / out of scope. The reset is silent.

### Preserved states (unchanged from current `DiffTab`)
- **Loading:** `"Loading diff…"` (`text-sm muted-foreground`), rendered only after a 150ms delay (no flash).
- **Empty:** `"No changes yet. The worktree matches "` + `<span class="font-mono">{base}</span>` + `"."` — centered, `muted-foreground`.
- **Error:** `"Couldn't load the diff."` (`text-sm`) + `error.message` (`text-xs muted-foreground`) + a `variant="outline" size="sm"` `"Reload diff"` button.
- **Refetch-with-data:** current content stays rendered; only the refresh button spins.

## Decisions & Rationale (for planner/executor)

1. **Tree click = scroll-only, no collapse/viewed mutation.** Deterministic and keeps DIFF-01/02/03 orthogonal; a collapsed or viewed file scrolled to via the tree stays as the user left it. (If UAT wants GitHub's expand-on-jump, that's a one-line follow-up.)
2. **Viewed uses `blue-500`, not the shadcn default `primary`.** The default checkbox fill is near-white (`primary` in dark); this surface's established interactive accent is `blue-500` (active tab, focus rings). Blue keeps the accent story consistent.
3. **Viewed checkbox is a sibling of the collapse trigger, not a child** — avoids invalid button-in-button (same constraint as the `TaskTabs` × close) and lets the two interactions stay independent.
4. **Sticky file headers** so the Viewed checkbox is always reachable on long files — matches GitHub and costs nothing (Radix already unmounts closed content).
5. **No "N of M viewed" progress, no split view, no per-line comments** — DIFF-FUT-01/02/03, explicitly out of scope.
6. **Fixed 288px tree, no splitter** — resizable panes are a future enhancement; keep the first cut simple.

Turn the single-scroll `DiffTab` into a GitHub "Files changed" two-pane layout: a fixed 288px left file tree (nested, path-compressed, folders-default-expanded) whose selection scrolls the right diff pane, with a scroll-spy that highlights whichever file is at the top of the viewport, and a `PanelLeft` toggle to hide/show the tree. <notes>
- **Scroll-spy: observe the WRAPPER, not the sticky header** (RESEARCH §Area 3 / Pitfall 3). A sticky element reports its pinned rect, confusing the topmost calc. The `data-diff-path` wrapper is the non-sticky `Collapsible` root (added in Plan 03).
- **IntersectionObserver MUST set `root: scrollRef.current`** (the right-pane `overflow-y-auto` div) — omitting root observes the viewport and the spy never fires per-file (Pitfall 3). `threshold: 0`; `rootMargin` ≈ `-41px 0px -70% 0px` to define a thin active band under the totals bar. Disconnect on cleanup; depend the effect on the joined path-list string (StrictMode-safe, re-observes on file-list change — Pitfall 4).
- **Click = scroll-only** (UI-SPEC Decision 1): `scrollIntoView({ block:'start', behavior: prefers-reduced-motion ? 'auto' : 'smooth' })`; the `scroll-mt-[41px]` from Plan 03 lands the header under the sticky totals bar (Pitfall 2). Never mutate collapse or Viewed on click.
- **Tree is nested-only, fixed w-72, not resizable** (D-07). Folders default expanded (D-06). Path-compress single-child dir chains only (stop at the first dir with >1 child or a file).
- The `use-scroll-spy.ts` hook file matches the `hooks/` convention (mirrors `use-mobile.ts` shape); it may alternatively live inline in DiffTab — a dedicated hook file is preferred here for testability of the effect boundary.
</notes>

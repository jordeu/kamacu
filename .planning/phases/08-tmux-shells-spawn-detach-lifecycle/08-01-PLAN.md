<interfaces>
Empirical truth table this package encodes (host tmux 3.4, verified 2026-06-12 — 08-RESEARCH.md Findings 1-14):

- `has-session -t =name`: exit 0 = alive; exit 1 = dead (covers BOTH "can't find session" AND "no server running" — identical exit codes).
- WITHOUT `=`, `has-session -t kangent-1` PREFIX-MATCHES `kangent-1-10` (exit 0!). `=` exact match is mandatory on every session target.
- `kill-session -t =name`: live → exit 0; dead session / dead server → exit 1 + stderr. Treat exit 1 as idempotent success.
- `-f <file>` is read exactly ONCE, by whichever invocation starts the server — passing it on EVERY invocation makes config application deterministic.
- The command-sequence alternative (`new-session -d \; set-option ...`) raced to "server exited unexpectedly" — rejected; use `-f`.
- `new-session -A` attaching with no tty fails `open terminal failed: not a terminal` — tests creating sessions directly must pass `-d`.
- tmux 3.4 pane-target commands (`send-keys`, `capture-pane`) reject bare `=name`; use `=name:` in tests. All production commands here are target-SESSION (bare `=name` works).
</interfaces>

```go
// DefaultSocket is the dedicated tmux socket name (-L) for all Kangent
// sessions — never the user's default server (settled roadmap decision).
const DefaultSocket = "kangent"

// Config is the Kangent-managed tmux configuration: status bar off (D-79),
// mouse on so wheel-scroll reaches tmux's real history (D-80), and a deep
// history-limit because tmux history IS the durable scrollback (default 2000
// is too shallow). Applied via -f on every invocation; tmux reads it exactly
// once, when an invocation starts the server.
const Config = `# kangent-managed tmux config (regenerated at startup -- do not edit)
set -g status off
set -g mouse on
set -g history-limit 50000
`

// WriteConfig writes Config to path (0o644), overwriting any previous file.
func WriteConfig(path string) error

// Client runs tmux verbs against one socket + config file.
type Client struct {
    Socket   string // -L socket name; DefaultSocket in production, per-test sockets in tests
    ConfPath string // -f config path; the generated file in production, "/dev/null" in tests
}

func (c Client) BaseArgs() []string                       // {"-L", c.Socket, "-f", c.ConfPath}
func (c Client) NewSessionArgs(name, dir string) []string // append(BaseArgs(), "new-session", "-A", "-s", name, "-c", dir)
func (c Client) HasSession(ctx context.Context, name string) (bool, error)
func (c Client) KillSession(ctx context.Context, name string) error
func (c Client) KillServer(ctx context.Context) error
```

Implementation rules:
- `NewSessionArgs` deliberately has NO `-d`: the caller (Manager.Spawn, plan 08-03) runs it under creack/pty as the foreground attach client. `-c` applies only at creation — names are fresh per tab, so that is correct.
- Every exec method wraps the caller's ctx with `context.WithTimeout(ctx, 5*time.Second)` (a hung tmux must never block Stop() or a cleanup HTTP request — Pitfall 5; 5s matches the D-14 grace scale) and uses `exec.CommandContext(ctx, "tmux", args...)` with an arg array — never `sh -c`.
- `HasSession` runs `append(c.BaseArgs(), "has-session", "-t", "="+name)`. Return values: run error nil → `(true, nil)`; `*exec.ExitError` with `ExitCode() == 1` → `(false, nil)` (dead session AND dead server both exit 1 — verified); any other error (binary missing, context timeout) → `(false, err)`. The err≠nil case is load-bearing: callers must never misread "tmux missing/hung" as "session dead" (Pitfall 6).
- `KillSession` runs `append(c.BaseArgs(), "kill-session", "-t", "="+name)`. Exit 0 → nil; `*exec.ExitError` exit 1 → nil (idempotent: already dead / no server); other errors → err.
- `KillServer` runs `append(c.BaseArgs(), "kill-server")`. Same idempotency: exit 1 → nil. (Used by test cleanup now; Phase 9's README escape hatch later.)
- The `"="+name` prefix appears ONLY on session targets and on every one of them — document the prefix-matching danger (Finding 2) in a comment.

```sql
CREATE TABLE tmux_sessions (
    id         INTEGER PRIMARY KEY,
    task_id    INTEGER NOT NULL REFERENCES tasks(id),
    n          INTEGER NOT NULL,

    label      TEXT    NOT NULL DEFAULT '',
    created_at TEXT    NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
    UNIQUE(task_id, n)
);
-- +goose Down

```

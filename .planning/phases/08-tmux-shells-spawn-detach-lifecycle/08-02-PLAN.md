```go
// AllowedShells returns the curated shell set (SHELL-01). "tmux" is offered
// only while the binary resolves on PATH (TMUX-01) — checked at call time so
// install/uninstall is reflected without a restart. LookPath on localhost is
// microseconds; both call sites (save-time validation, GET options) share it,
// so the dropdown offering and the save acceptance can never disagree.
func AllowedShells() []string {
	shells := []string{"bash"}
	if _, err := exec.LookPath("tmux"); err == nil {
		shells = append(shells, "tmux")
	}
	return shells
}
```

Update the `Validate` KeyShell arm to call it: `for _, s := range AllowedShells() {`. Keep the `"Unknown shell."` error string byte-identical. `os/exec` is already imported.

In `internal/api/settings.go` `entryFor`, change `e.Options = settings.AllowedShells` to `e.Options = settings.AllowedShells()`. Keep the "Same slice as save-time validation — one source of truth." comment intent (reword to "Same function as save-time validation — one source of truth.").

Note the honest edge this buys (document nothing extra — behavior emerges): if tmux disappears from PATH, the option vanishes from the dropdown AND re-saving "tmux" is rejected, while an already-stored `shell=tmux` row still flows to spawn where D-84's honest error fires (plan 08-04).

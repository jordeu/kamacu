## The View State Matrix (LOCKED — the core interaction contract)

One `GET /api/global` response (`globalConfig`, `internal/api/global.go:48-56`) drives the entire `/global` view (D-17/D-39/D-40). The shared TanStack query is keyed `["global"]`, consumed by BOTH the Settings section and `/global`, `refetchInterval: 5000` while mounted (matches the app's 5s poll idiom; the stat/probe cost is trivial). Exact precedence, evaluated top-down:

| # | Condition (from GET) | Renders | Source |
|---|----------------------|---------|--------|
| 1 | query pending | Page skeleton (TaskPage pending idiom: `max-w-[860px] space-y-4 p-4` + Skeleton rows) | default |
| 2 | query error | Centered `Couldn't load the scratchpad.` + outline `Retry loading` (SettingsPage error idiom, `SettingsPage.tsx:128-137`) | default |
| 3 | `root_path === ""` | **D-39 unconfigured full-page state** → Settings | GVIEW-04, D-39 |
| 4 | `root_path !== "" && !root_exists && live.{agent,bash,tmux} all 0` | **D-40 vanished-root full-page state** → Settings | D-40 |
| 5 | `root_path !== "" && !root_exists && any live count > 0` | Full task-parity shell + **D-42 warning banner** (replaces the isolation banner slot) — terminals keep streaming, nothing killed/detached | D-42 |
| 6 | folder root (`github_repo === null`) && `root_exists` | Full task-parity shell + **D-38 isolation banner** (persistent) | D-38 |
| 7 | managed clone (`github_repo !== null`) && `root_exists` | Full task-parity shell, **NO banner** | D-38 |

Rules:

- States 3 and 4 are DISTINCT full-page states — a vanished root is NEVER rendered as the generic unconfigured state (D-40, deliberate misconfiguration-vs-disk-rot distinction).
- State 5 is the warn-don't-disturb posture: attached terminals own their cwd; stopping/reconfiguring stays the user's call. No kill, no detach, no modal.
- The `live` counts are the wire's real Phase-15 values (`globalLive`, `global.go:35-39`) — the client never guesses liveness.
- The banner is a slot: exactly one of {D-38 isolation, D-42 warning} renders, never both, never neither in states 5/6.

## Surface 1: The `/global` Shell (GVIEW-01)

### Route registration

`/global` registers in `App.tsx` inside `AppLayout` (the bar must be present), as a sibling of `/settings` and `/activity` — **NOT** wrapped in `BoardWorkspaceSync` (no `:projectId` param exists; CONTEXT integration points). Lazy-loading follows whatever `App.tsx` already does (currently none — plain imports).

### Page frame

```
┌────────────────────────────────────────────────────┐
│ Scratchpad                    [QuotaIndicator?]     │  ← header row (D-35, D-37)
│ ⚠ Agent runs directly in /path — no worktree iso…  │  ← banner slot (D-38/D-42), states 5/6 only
│ ┌────────────────────────────────────────────────┐ │
│ │[Agent ●] [Bash 1] [Bash 2…            (+)]     │ │  ← TaskTabs strip, trailing "+"
│ │                                                │ │
│ │              tab content                       │ │
│ └────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

- Page container: `flex h-full w-full flex-col gap-6 p-4` — the TaskPage working-surface idiom (`TaskPage.tsx:481`). Full width; terminals get the whole main area.
- **Header (D-35):** `<h1 className="text-base font-medium">Scratchpad</h1>` — the SettingsPage h1 idiom (`SettingsPage.tsx:143`). NO back-arrow (top-level destination like `/settings`), NO page-level ⋯ menu (no task to delete, no worktree to clean). The title is a static label — not editable, not a button.
- **QuotaIndicator (D-37):** right-aligned in the header row. Same claude-engine rule as TaskPage: resolved from the global default agent's `engine` (from `GET /api/global` → `agent.engine`) using TaskPage's exact `isClaudeAgent` approach (`TaskPage.tsx:64`) — hidden for custom/opencode engines. Both underlying queries (`["global"]`, quota) are cached/shared — no new fetches.
- **NO Esc-to-board handler.** TaskPage's Esc navigates to a parent board (`TaskPage.tsx:228-244`); `/global` has no parent board. Do not add an Escape handler — the sidebar and bar are the navigation. (Suppressed-while-typing semantics are irrelevant without the handler; the TerminalPane key handling is unaffected.)

### Banner slot (D-38 / D-42)

Both banners use the app's standing amber warning idiom (the TaskPage merged/closed PR banner, `TaskPage.tsx:642`), dark-only:

```jsx
<div role="status"
     className="flex flex-wrap items-center gap-2 rounded-md border border-amber-500/30 bg-amber-500/10 px-2 py-1 text-xs text-amber-400">
```

- **D-38 isolation banner** (state 6): persistent, one line, NOT dismissible, rendered under the header above the tab strip, visible whichever tab is active (bash tabs run un-isolated too). Copy LOCKED (13-UI-SPEC row 10): `Agent runs directly in {root} — no worktree isolation.` with `{root}` in `font-mono`. Hidden for managed clones (state 7 — the clone namespace IS the isolation boundary).
- **D-42 warning** (state 5): same idiom and slot, replacing the isolation banner. Draft copy: `The configured root no longer exists on disk: {path}. Running sessions are unaffected.` with `{path}` in `font-mono`. `role="status"` (advisory) — never `alert`, never blocking (warn-don't-disturb).

### Tab strip (GVIEW-01)

`TaskTabs` with a `TabDef[]` of EXACTLY: `[agent, ...visibleBashSessions]`. NO description tab, NO diff tab, never a kanban board (REQUIREMENTS Out-of-Scope). Bash-tab visibility/muting/closing/rename logic is task parity (TaskPage's `visibleSessions`/`closingIds`/`keepExitedIds` mechanics, `TaskPage.tsx:116-188`).

- **Agent tab:** `label: "Agent"`, `leading: <StatusDot/>` when a global status entry exists (state dot from the `useAgentStatuses` feed — global entries arrive server-side since Phase 15), `keepMounted: true` (tab switches never detach the WS), NO `onClose` (permanent tab).
- **Bash tabs:** server labels (`Bash <n>` — `defaultTmuxLabel` parses `kamacu-global-<n>` unchanged, 13-UI-SPEC row 13), `onClose`/`onRename` while running, `keepMounted: true`, `min-h-[320px]` content — all task parity via `TerminalPane`.
- **Trailing "+":** the TaskPage idiom verbatim (`TaskPage.tsx:443-474`) — ghost `icon-sm` Button, `aria-label="New bash session"`, Plus icon, tooltip, and the inline 409 span (see § Copywriting row 18). `canSpawn` = root configured + root exists (states 5/6/7) — i.e. disabled exactly when the banner slot is empty because the view is degraded; in state 5 spawning stays enabled (warn, don't block).

### Agent tab states (task parity, D-36/D-41)

`AgentTab` is reused with loosened props — NOT forked (research-locked). Its four states map 1:1 onto the global scope:

| State | Rendering | Divergence from task |
|-------|-----------|---------------------|
| Pre-start (D-41) | Centered `flex flex-col items-center gap-2 py-8 text-center`; `h2 text-xl font-medium` `No agent session`; body `text-sm text-muted-foreground` (copy row 13); primary Button `Start agent` → `Starting…` (`AgentTab.tsx:96-133`) | Body copy names the root instead of a worktree/branch; no worktree gating — the CTA is enabled whenever the shell renders (states 5/6/7) |
| Resumable pre-start | `Agent session ended.` + Reset/Resume pair, mutual-exclusion `busy` (`AgentTab.tsx:71-93`) | None — engine-branched resume via scope-aware `useResumeAgent` variant |
| Running | `TerminalPane` + `headerMenu` ⋯ | **D-36: the ⋯ menu renders exactly ONE item — `Stop` (destructive variant).** "Insert description" (no description exists) and "Insert review prompt" (no PR concept) degrade away. No separator before a lone item |
| Exited | `Agent session ended.` banner, dimmed terminal, `Reset session` (+ Resume pair when `resumable`) (`AgentTab.tsx:213-250`) | None |

- Spawn goes through the Phase-15 surface: `POST /api/sessions {scope:"global", kind:"agent"}`; a second concurrent spawn 409s (`global agent already running`) and surfaces verbatim (§ Copywriting row 18).
- The `resumable` driver is the server's flag on the global status entry — never inferred client-side (AgentTab's single-driver rule, `AgentTab.tsx:54-59`).
- Sessions listing: `GET /api/sessions?scope=global` under a `["sessions", "global"]` key (scope-aware variant of `useSessions`; 5s refetch parity).

Both are full-page replacements of the shell (not banners, not modals), sharing one component shape in the centered-hero idiom (the `RedirectToFirstProject` / AgentTab empty-state pattern, `App.tsx:41-54`):

| | D-39 Unconfigured (state 3) | D-40 Vanished root (state 4) |
|---|---|---|
| Heading | `Scratchpad isn't configured yet` (D-39 content) | `The Scratchpad root no longer exists` *(draft)* |

## Surface 3: Settings Scratchpad Section (GCONF-05, D-43..D-46)

### Section placement & frame

Recommended placement: directly after `AgentsSection` (both govern where agents run) — planner may reorder within the column.

### Summary card (D-44) — composed, not a shadcn add

`<div className="rounded-lg border bg-card p-4">` hosting three rows (`flex flex-col gap-4` inside):

**Row 1 — Root.** Label `Root` (`text-xs font-medium`), then:
- Folder root: `<span className="font-mono text-sm truncate" title={path}>{root_path}</span>`
- Managed clone: `<span className="font-mono text-sm">{owner/name}</span>` + `<Badge variant="secondary">managed</Badge>` (the marker is the non-null `github_repo` pointer — never a boolean on the wire)
- Unconfigured: `<p className="text-sm text-muted-foreground">{`No root configured yet.`}</p>` *(draft)*

**Row 2 — Default agent (D-46).** Label `Default agent`, then the ProjectSettingsDialog Select idiom verbatim (`ProjectSettingsDialog.tsx:234-246`): `Select` listing `useAgents()` items as `{a.name}{a.is_default ? On failure: inline `text-xs text-destructive` `Couldn't save. Try again.` (the canonical retry copy), selector snaps back to the saved value. **Row 3 — Actions.** `<div className="flex items-center gap-2">`:
- `Open Scratchpad` — **default (primary inverted) variant**, navigates to `/global`. This is the GCONF-05 idle-reachability affordance; the single primary CTA of the section.
- `Change root…` — `variant="outline"`; when unconfigured the label reads `Configure root…` *(draft)*. Opens the Change-root dialog.

### Change-root dialog (D-43 — AddProjectDialog pattern verbatim)

`Dialog` + `DialogContent className="sm:max-w-[480px]" aria-describedby={undefined}`, `DialogTitle` `Scratchpad root`. Derived from `AddProjectDialog.tsx` with these deltas:

| Aspect | Contract |
|--------|----------|
| Segmented toggle | `Tabs` with `TabsList aria-label="Scratchpad root source" className="w-full"`, triggers `GitHub repo` / `Local folder` — rendered ONLY when GitHub integration is on; folder-only when off (`AddProjectDialog.tsx:166-179` idiom). Repo default when integration on |
| Repo mode field | Label `Repository`; `Input className="font-mono" placeholder="owner/name"`; help/error exactly one of {help, error} shows (`AddProjectDialog.tsx:196-206`) |
| Folder mode field | Label `Repository path`; `Input className="font-mono" placeholder="/home/you/code/my-repo"` |
| **NO Name field** | The scratchpad has no name — the AddProjectDialog Name field and its prefill machinery are dropped |
| Submit | `Save root` — repo mode sends `PUT {repo: "owner/name"}`; folder mode sends `PUT {root_path: "/abs/path"}`. Submit disabled while field empty or pending |
| Cloning | Blocking `Loader2` spinner + `Cloning {owner/name}…` (`text-sm text-muted-foreground`, mono ref) while the repo PUT runs (`AddProjectDialog.tsx:250-259` idiom) |

### 409 gate surfacing (D-45)

A blocked change/clear renders the `{error, reasons[...]}` body **verbatim** inside the open dialog's error box: `sentenceCase(error)` as the lead sentence, then the reasons as a plain `<ul className="list-disc pl-4">` of `text-xs` items — wire strings verbatim, NO client re-wording (CONTEXT specifics). Wire reasons grammar (13-UI-SPEC row 11): `agent session running`, `2 bash tabs running` — terse, lowercase, count-carrying when N>1. 400 validation messages surface `sentenceCase(err.message)` verbatim (the `~/.kamacu` footgun block included, D-27). Network/5xx: `Couldn't save. Try again.`

## Surface 4: Active Sessions Bar Row (GINT-01)

The ONE existing file this phase edits for the bar: `ActiveSessionsBar.tsx`. Three changes, nothing else:

1. **Re-key rows by `sessionId` (P6, research-locked):** `key={entry.sessionId}` replaces `key={entry.taskId}` (`ActiveSessionsBar.tsx:129`). A global entry's `taskId` is `0` — and at most ONE global entry exists (one-agent gate D-34), so `0` was unique-but-dead; `sessionId` is unique for every live row (the `""` sessionId only occurs on DB-derived `exited` entries, which the LIVE filter removes before render). Safe for task rows too — sessionIds are unique per row.
2. **`source === "global"` navigation branch:** `onOpen` for a global entry is `navigate("/global"); collapse();` — task rows keep `/projects/{projectId}/tasks/{taskId}`. This replaces the Phase-15 interim dead-route artifact (`/projects/0/tasks/0`) with the real destination.
3. **Current-page highlight:** a global entry's `isCurrent` is `useLocation().pathname === "/global"` (no taskId param exists there); task rows keep `String(entry.taskId) === openTaskId`. Highlight treatment unchanged: the non-chromatic `bg-sidebar-accent text-sidebar-accent-foreground` idiom (`ActiveSessionsBar.tsx:257`).

Row rendering is otherwise UNTOUCHED — the standard `SessionRow` slots render `[dot] Global · Scratchpad` (wire-synthesized `projectName`/`taskTitle`, locked strings), aria-label derives to `Open Scratchpad in Global` via the existing template, standard `dotMeta` palette, standard `min-h-9 gap-2 px-2 py-1.5 text-sm` metrics, counts toward the collapsed working/waiting/idle/running groups, sorts by the standard attention-first rank with no special branch. **NO visual differentiation** — no icon, no badge, no tint (D-12 defers the globe-badge-vs-text-only treatment to Phase 17 UAT).

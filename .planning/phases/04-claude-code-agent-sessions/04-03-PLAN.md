  <action>
    `web/src/api/agents.ts` — new file:
    ```ts
    import { useQuery } from "@tanstack/react-query";
    import { get } from "./client";

    export interface AgentStatusEntry {
      taskId: number;
      projectId: number;
      sessionId: string;
      status: "working" | "idle" | "waiting" | "exited";
      exitCode: number | null;
      stopRequested: boolean;
    }

    /** Single source of truth for card dots, the Agent tab dot, and sidebar
     *  chips (research Pattern 4) — one query, no per-project fan-out. */
    export function useAgentStatuses() {
      return useQuery({
        queryKey: ["agent-statuses"],
        queryFn: () => get<AgentStatusEntry[]>("/api/agents/status"),
        refetchInterval: 5000, // UI-SPEC: waiting surfaces within 5s
      });
    }
    ```

    `web/src/components/StatusDot.tsx` — new file (placed at components root: consumed by board/, task/, and referenced by sidebar logic). Export two things:

    1. `dotMeta(entry: Pick<AgentStatusEntry, "status" | "exitCode" | "stopRequested">): { className: string; tooltip: string }` — pure mapping per D-43 + research OQ4 (stop-initiated exit 143 is GRAY, not red):
       - working → `bg-green-500`, `Working`
       - waiting → `bg-amber-400 animate-pulse motion-reduce:animate-none`, `Waiting for input`
       - idle → `bg-zinc-400`, `Idle`
       - exited with (entry.exitCode === 0 || entry.stopRequested) → `bg-zinc-600`, `Exited (code {N})` — tooltip ALWAYS shows the real code (e.g. `Exited (code 143)`), only the color is softened
       - exited otherwise → `bg-red-500`, `Exited (code {N})`

    2. `StatusDot({ entry, className })` component: a Tooltip-wrapped span. Outer span = TooltipTrigger (the wrapper takes hover; the dot itself is non-interactive and must never intercept card click/drag — UI-SPEC). Inner dot span: `size-2 rounded-full shrink-0` + dotMeta className. `aria-label={'Agent status: ' + tooltip.toLowerCase()}` on the dot span (role="img"). TooltipContent renders the tooltip text. No border/ring on the dot itself, no icon — a dot, period.

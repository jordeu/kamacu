    Constants (package level, tunable per D-47): `agentSettleWindow = 2 * time.Second`, `agentQuietThreshold = 10 * time.Second`.

    Methods (each takes s.mu):
    - `SetWaiting()` — waiting = true. (Notification hook.)
    - `SetIdle()` — waiting = false; stopHookAt = now; lastActivity = time.Time{} (zero so status computes idle IMMEDIATELY — Pitfall 1's first half). (Stop hook.)
    - `MarkHooksAlive()` — hooksAlive = true. (SessionStart hook.)
    - `ClearWaitingOnAttach()` — if kind == KindAgent && waiting: waiting = false; lastActivity = time.Time{} (→ idle, D-45). No-op for bash.
    - `ClaudeSessionID() string` — accessor.
    - In `WriteInput`: if kind == KindAgent (under the existing lock acquisition): waiting = false; lastActivity = now. (stdin → working, clears waiting — state machine line.)
    - In `Stop()`: set stopRequested = true under s.mu inside the stopOnce.Do body, BEFORE signaling.
    - In `pump()`, inside the existing s.mu critical section, when kind == KindAgent:
      ```go
      if bare := s.bel.scan(chunk); bare > 0 && !s.hooksAlive {
          s.waiting = true // BEL fallback ONLY in hooks-dead mode (Pitfall 2)
      }
      if !s.waiting && time.Since(s.stopHookAt) > agentSettleWindow {
          s.lastActivity = time.Now() // output → working, post-settle, never from waiting
      }
      ```
    - Lazy status computation (research recommendation — no ticker goroutine; the 5s poll is the only consumer). Private helper called from Info() with mu held:
      ```go
      func (s *Session) agentStatusLocked() string {
          if s.status == StatusExited { return "exited" }
          if s.waiting { return "waiting" }
          if !s.lastActivity.IsZero() && time.Since(s.lastActivity) < agentQuietThreshold { return "working" }
          return "idle"
      }
      ```
    - `Info` struct gains three JSON fields:

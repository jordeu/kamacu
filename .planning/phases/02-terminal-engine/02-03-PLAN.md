    ```go
    const (
        FrameData   byte = '0' // 0x30 both directions
        FrameResize byte = '1' // 0x31 client→server
        FrameExit   byte = 'x' // 0x78 server→client
    )
    const CloseSessionNotFound websocket.StatusCode = 4404 // RFC 6455 private-use range
    ```

    `internal/ws/handler.go` — `type Handler struct { mgr *session.Manager; originPatterns []string }`, `func NewHandler(mgr *session.Manager, originPatterns []string) *Handler`, implementing `ServeHTTP`:
    1. `id := r.PathValue("id")`; look up session. Accept FIRST in all cases (you cannot send a WS close code without completing the upgrade):
       `conn, err := websocket.Accept(w, r, &websocket.AcceptOptions{OriginPatterns: h.originPatterns})` — InsecureSkipVerify stays false (default). If session missing → `conn.Close(CloseSessionNotFound, "session not found")` and return.
    2. `conn.SetReadLimit(1 << 20)` — library default is 32 KiB; a large bracketed paste would otherwise kill the conn with StatusMessageTooBig (Pitfall 2).
    3. `connID := uuid.NewString()`; `q := sess.Attach(connID)`; `defer sess.Detach(connID)`. Detach NEVER touches the PTY — that IS TERM-05.
    4. Writer goroutine (the ONLY writer for this conn — guarantees output ordering): drain q; for each chunk build frame `append([]byte{FrameData}, chunk...)` and `conn.Write(ctx, websocket.MessageBinary, frame)`. Select on `sess.Done()`: when it fires, send `FrameExit` frame with JSON `{"code":N}` from `sess.Info().ExitCode`, then `conn.Close(websocket.StatusNormalClosure, "")` and return. Also select on a per-conn ctx so reader-side close stops the writer.
    5. Read loop (this goroutine; reads must be serialized — coder/websocket rule): `typ, data, err := conn.Read(ctx)`; on err return. Dispatch on data[0]:
       - FrameData → `sess.WriteInput(data[1:])`
       - FrameResize → `json.Unmarshal(data[1:], &struct{Cols, Rows uint16}{...})` → `sess.Resize(cols, rows, firstResizeSinceAttach)`; set the flag false after the first call. forceRedraw=true exactly ONCE per attach (jiggle debounce — claude-code resize-storm bug).
       - Ignore unknown bytes ('2'/'3' reserved).
       Binary frames ONLY — never text frames for PTY bytes (UTF-8 validation corrupts split sequences).
    Tests: table-driven, httptest.NewServer with a real ServeMux route `GET /api/sessions/{id}/ws`, real manager + bash sessions, `websocket.Dial` from the test with `HTTPHeader` to control Origin. originPatterns for tests: the httptest server's own host is auto-authorized (request Host always allowed), so the evil-origin test works without extra patterns.
  </action>

## Copywriting Contract

Tone inherited: terse, sentence case, no exclamation marks, no "please".

| Element | Copy |
|---------|------|
| Primary CTA (page header) | `New terminal` — spawns a session and attaches immediately. The only inverted high-contrast element on the page (focal point) |
| Page title | `Terminal` |
| Session label (discretion — resolved) | `bash #{N}` — N is server-assigned spawn order, monotonic per server lifetime, never reused. Rendered 14px/500. No user renaming in Phase 2 |
| Session row meta — live | `running` (12px muted label) |
| Session row meta — exited | `exited (code {N})` (12px muted label) |
| Empty state — no sessions | Heading (Display): `No sessions`. Body: `Start a shell that keeps running even when you close this tab.` CTA: `New terminal`. Centered in the pane area, 2xl vertical padding |
| Empty state — none selected (sessions exist) | Muted body, centered: `Select a session to attach.` |
| Exited banner (D-15) | `Session exited (code {N})` 14px/500 + actions `New terminal` (small primary) / `Close` (ghost). Signal deaths render whatever code the server reports — no special-casing copy |
| Connecting (initial attach) | Centered muted body in pane: `Connecting…` — only shown if attach takes >150ms (no flash) |
| Reconnecting (transient WS drop) | Banner: `Connection lost. Reconnecting…` (muted body). No actions — automatic |
| Connection lost (retries exhausted) | Banner: `Couldn't reconnect.` + body `The session may still be running on the server.` + `Retry` button (ghost) |
| Session not found (attach to dead/unknown id) | Banner: `Session not found.` + actions `New terminal` / `Close` |
| Stop action | Button: `Stop`. During SIGTERM grace window (~5s, D-14): disabled, label `Stopping…`. No confirmation dialog — D-14 specifies one button; this is a dev surface killing a shell, not data |
| New terminal failure | Inline near the button, destructive 12px text: `Couldn't start a session. Try again.` |

Note: `Stop` is destructive-adjacent but unconfirmed by explicit decision (D-14 "one button"). Phases 3–4 may add confirmation for agent sessions; not this phase's call.

## Interaction Contract

States the executor must implement; the auditor will check these.

| Interaction | Contract |
|-------------|----------|
| New terminal | Click → POST spawn → row appears in rail (selected) → pane attaches. Button disabled while the request is in flight; no spinner row |
| Attach by click (D-13) | Clicking any session row attaches the pane to it (live: replay ring buffer then live stream; exited: frozen final output + exited banner). Switching rows detaches the previous WS cleanly |
| Replay on reattach | Ring-buffer replay written to a fresh xterm, then a resize nudge (fit → send cols/rows) forces TUI repaint. User-visible contract: reopening mid-`htop` redraws correctly; brief replay flicker acceptable, corrupted screen is not |
| Resize | fit addon driven by ResizeObserver on the pane; on fit, send `{cols, rows}` over WS. Terminal always fills the pane — no fixed cols |
| Scrollback | `scrollback: 10000` (D-18). xterm default scrollbar styling |
| Copy/paste (D-17) | `copy-on-select` enabled; Ctrl+Shift+C copies selection; Ctrl+Shift+V pastes; bracketed paste sequences pass through to the PTY untouched. Right-click uses browser default (no custom context menu) |
| Keyboard capture | Focused terminal consumes keystrokes (expected — including `n`, Ctrl+B). Global shortcuts apply only when focus is outside the terminal. Esc goes to the PTY, never navigates |
| Focus | Clicking anywhere in the terminal viewport focuses xterm; container shows the accent focus-visible ring only for keyboard focus (`:focus-visible`), not pointer clicks |
| Stop (D-14) | Click `Stop` → button becomes disabled `Stopping…` → on exit notification the pane shows the exited banner and the rail row flips to `exited (code N)`. If SIGKILL fallback fires, same UX — the grace window is invisible apart from the delay |
| Exited session (D-15) | Output frozen; banner docked at the TOP of the terminal viewport (zinc-900 strip, 1px zinc-800 bottom border, sm/md padding) so scrollback below stays fully scrollable and copyable. Banner intercepts pointer events; the rest of the pane does not. `Close` removes the session from the rail and shows the appropriate empty state |
| Auto-reconnect (discretion — resolved) | On transient WS close: auto-retry with exponential backoff 0.5s → 1s → 2s → 4s → 8s (5 attempts), reconnecting banner visible, terminal input disabled but scrollback usable. Success: banner clears, replay + resize nudge runs. Exhausted: lost banner with `Retry` (restarts the cycle). Server-reported session-gone (close code) skips retries → `Session not found.` banner |
| Loading | Rail initial load: 2 skeleton rows (existing shadcn skeleton). Pane: `Connecting…` rule above. No full-page spinners |
| No idle timeout (D-16) | No idle indicators, no "session will expire" copy anywhere |

## Layout Contract

| Region | Spec |
|--------|------|
| Route | `/terminal` under `AppLayout` (sidebar remains visible) — added to `web/src/App.tsx` routes (D-12). Dev-only surface; no sidebar nav entry required (reached by URL), adding a temporary nav link is permitted but must use standard sidebar row styling |
| Page header | Row: `Terminal` heading (16px/500) left, `New terminal` button right. xl (24px) padding consistent with board page chrome |
| Body | Two columns, lg (16px) gap: session rail (fixed 220px) + terminal pane (fills remainder). Pane height: fill viewport below header (terminal real estate is the point) |
| Session rail | Vertical list, rows: md horizontal / sm vertical padding, two lines — label 14px/500 + meta 12px muted (`running` / `exited (code N)`), ~48px natural height. Live sessions sorted above exited, newest first within each group. Selected: `#27272a` + zinc-50. Exited rows: muted label |
| Terminal pane | 1px zinc-800 border, Phase 1 radius. Header bar 36px: session label (14px/500) left, connection status (12px muted, only when not cleanly connected) center/right, `Stop` (ghost destructive, only for live sessions) right. 1px zinc-800 separator below header. Viewport: xterm with sm (8px) inset painted `#09090b` |
| Banners (exited / reconnecting / lost / not found) | Full-width strip docked under the pane header, above the viewport: zinc-900, sm vertical / md horizontal padding, message left, actions right. One banner at a time |
| Empty states | Centered in the pane area (rail still visible when sessions exist) |
| Phase 3 portability (D-12) | `TerminalPane` (header + banners + xterm viewport) must be self-contained — props: session id (or WS URL) only; no `/terminal`-route imports. The rail and page header are route-level composition. When re-mounted in `TaskTabs`, the pane border may be dropped (the tab content area provides framing) but theme, banners, and states are identical |

Focal point: `New terminal` is the only inverted high-contrast element; the terminal viewport (the product) dominates the page area.

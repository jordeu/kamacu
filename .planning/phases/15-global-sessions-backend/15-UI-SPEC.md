## Wire Contract: `agentStatusEntry` Global Entry

The authoritative UI-relevant wire spelling (locked — 15-RESEARCH Spike 1, verified consumer-by-consumer at file:line; CONTEXT D-09/D-10):

| Field | Value | UI Meaning |
|-------|-------|------------|
| `source` | `"global"` | The discriminator Phase 16 branches on. Extends the existing `"manual" \| "github_pr"` union SERVER-side only — the TS union widens in Phase 16 (runtime value flows through unrecognized, harmlessly) |
| `taskId` | `0` | Zero value, NEVER null/absent — `AgentStatusEntry.taskId: number` stays non-nullable (`web/src/api/agents.ts:5`); zero never equals a real id (SQLite rowids start at 1) |
| `projectId` | `0` | Same — non-nullable zero |
| `sessionId` | real session id (live pass) / `""` (DB-derived post-restart pass) | Phase 16's bar key (P6); not consumed in this phase |
| `status` | real state: `working` / `waiting` / `idle` (claude hooks) or `running` (opencode); `exited` in the DB-derived pass | Drives the standard state dot + collapsed counts |
| `taskTitle` | `"Scratchpad"` | Server-synthesized (D-09). LOCKED string |
| `projectName` | `"Global"` | Server-synthesized (D-10). LOCKED string |
| `prNumber` | `null` | The bar's `#n` badge check (`source === "github_pr"` && `prNumber != null`) is false — no badge |
| `resumable` | engine-branched truth | Not rendered this phase; Phase 16 resume affordance |
| `exitCode` / `stopRequested` | real values | Standard dotMeta behavior |

**Emitted in BOTH passes** (co-phasing mandate — Pitfall 1): the manager-derived live pass AND the DB-derived post-restart pass. The DB-pass entry (`status:"exited"`, `resumable:true`) is filtered out client-side by the bar's existing LIVE filter — post-restart, the interim row disappears until resumed. Correct and accepted.

**Existing-consumer safety (verified — no frontend changes required):**

| Consumer | Lookup | Effect of `{taskId:0, projectId:0}` |
|----------|--------|-------------------------------------|
| `TaskPage.tsx:87`, `AgentTab.tsx:58` | `find(e => e.taskId === task.id)` | Never matches (ids ≥ 1) — safe by construction |
| `TaskCard.tsx` / `PRCard.tsx` | task/pr linkage per card | Never matches — safe |
| `ProjectSidebar.tsx:41-44` | `waitingByProject.get(entry.projectId)` | Gains a dead `0`-key no project reads — safe |
| `StatusDot.tsx` | status/exitCode only | Renders fine |
| `ActiveSessionsBar.tsx:129-135` | renders ALL live entries; `key={taskId}`; nav `/projects/{projectId}/tasks/{taskId}` | **The one interim artifact** — specified below |

## Interim ActiveSessionsBar Behavior (LOCKED)

**Decision: accept the interim artifact — zero frontend changes in Phase 15.** A live global agent session renders as a standard bar row that navigates to the dead route `/projects/0/tasks/0` until Phase 16 branches on `source`. Do NOT add a non-navigating/disabled guard, a `source` union widening, or any suppression: any of those is a frontend change that violates the phase boundary (CONTEXT: "Curl/API-testable only — no frontend") and forks Phase 16's bar work. Deferring the status widening to avoid the row violates the co-phasing mandate (roadmap, non-negotiable).

**Accepted-risk rationale (RESEARCH A2):** v1.13 is unreleased mid-milestone; local-only, single user; the artifact self-heals at Phase 16.

Exact interim rendering (all inherited — the row is the existing `SessionRow`, unchanged):

| Aspect | Contract |
|--------|----------|
| Row content | `[state dot] Global · Scratchpad` — standard `[dot] {projectName} · {taskTitle}` layout |
| State dot | Standard `dotMeta` palette: working `bg-green-500`, waiting `bg-amber-400` pulse, idle `bg-zinc-400`, running `bg-blue-500`. No special dot, no new color |
| Visual differentiation | **None.** No icon, no badge (`prNumber:null` + source check false), no tint — visually a peer of task rows. Differentiation is Phase 16's GINT-01 work |
| Row metrics | Inherited: `min-h-9`, `gap-2`, `px-2 py-1.5`, `text-sm`, truncated title with `title="Scratchpad"` tooltip |
| React key | `key={entry.taskId}` → `0` — unique: the one-agent gate (D-34) + the DB-pass skip guarantee at most ONE global entry |
| Click / Enter / Space | Navigates to `/projects/0/tasks/0`; the bar collapses (standard SBAR-06 behavior) |
| Dead-route landing | `TaskPage` renders its existing not-found state: "Task not found." (`TaskPage.tsx:258-261`) — an honest dead end, not a crash or blank page |
| `aria-label` | Standard pattern: `Open Scratchpad in Global` |
| Collapsed counts | The global entry counts toward working/waiting/idle/running groups like any live session — no exclusion, no separate count |
| Current-page highlight | `isCurrent` compares `"0"` to route params — never true on real routes (interim). If the user re-expands the bar while on `/projects/0/tasks/0`, the row highlights; harmless |

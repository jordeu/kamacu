<objective>
Make deleting a managed-checkout project clean up its directory safely: gate every task worktree AND the clone root on the same four conditions as worktree cleanup (dirty / unpushed / stash / running session); if anything is blocked, refuse with a 409 reason list and remove nothing (all-or-nothing, D-07); when all clear, remove each linked worktree first, then `os.RemoveAll` the clone dir, then delete the project row. Folder (user-pointed) project delete is byte-for-byte unchanged — its directory is never touched (D-09).

Purpose: CKOUT-03. The unpushed gate is the safety net (D-08): removing the clone dir discards local-only branches, so the delete must refuse while unpushed commits exist. A missing/incorrect marker check is a data-loss risk (deleting a user's working checkout) — the `managed` column is the single source of truth.
Output: A managed branch in `projectHandlers.delete` (two-pass gate→remove) plus tests for each gate, all-clean removal, and the unchanged folder path.
</objective>

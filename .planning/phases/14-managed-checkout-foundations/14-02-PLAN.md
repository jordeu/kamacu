    Logic (research §"Reattach on Existing Dir"):
    1. Confirm dest is a git repo: `exec.CommandContext(ctx, "git", "-C", dest, "rev-parse", "--git-dir").Run()` — on error → `fmt.Errorf("a directory already exists at %s but is not a git repository", dest)`.
    2. Read origin: `out, err := exec.CommandContext(ctx, "git", "-C", dest, "remote", "get-url", "origin").Output()` — on error → `fmt.Errorf("a directory already exists at %s with no origin remote", dest)`.
    3. `got, perr := github.ParseRepoRef(strings.TrimSpace(string(out)))` — handles ssh + https (research §"origin URL form"). On perr OR `!strings.EqualFold(got, canonical)` → `fmt.Errorf("a different repository is already checked out at %s", dest)` (use case-insensitive compare since gh canonicalizes casing).

<objective>
Make managed-checkout task/PR-review worktrees start from the freshest default branch: before `provisionWorktree` resolves the base, if the project is managed, best-effort `git fetch origin <defaultBranch>` in the clone (CKOUT-02/D-04). The fetch is best-effort (D-05) — a failure proceeds from the local base, never blocking task creation — and is gated on `managed` so folder projects keep `ResolveBase`'s D-24 "no network, ever" guarantee untouched.

Purpose: This is the freshness half of CKOUT-02. The single choke point is `provisionWorktree` (used by task-create AND the POST /worktree Retry AND PR-review provisioning), so threading `managed` here covers every worktree-creation surface.
Output: `loadTaskRepo` selects `managed`; the task-create caller passes it; `provisionWorktree` takes a `managed bool` and inserts a managed-only best-effort fetch before `ResolveBase`.
</objective>

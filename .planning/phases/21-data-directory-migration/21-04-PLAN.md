<objective>
Wire the two-part migration one-shot into the `cmd/kamacu/main.go` startup sequence and flip every
remaining runtime `kangent` literal that Phase 20 deliberately left in place: the `--db` default, the
tmux socket + session prefix + config header, the managed-clone root, the worktree-base default, and
the worktree root. This is the atomic point where the running app switches to `~/.kamacu` and
`-L kamacu` (MIGRATE-01 runs-against-new-location, MIGRATE-03 socket/prefix switch, MIGRATE-05
refuse-to-boot wiring).

Purpose: The migrate package (Plans 21-02/03) is inert until called. Ordering is load-bearing
(RESEARCH Pitfall 4): Part 1 MUST run before `os.MkdirAll`/`store.Open` (creating `~/.kamacu` early
defeats the "dst absent" gate and makes `os.Rename` fail); Part 2 MUST run after `store.Migrate` (it
needs the schema). The socket/prefix flip and the DB tmux-row cleanup (Plan 21-03) together keep a
reopened task from looking for a session that no longer exists.
Output: 5 modified files; the app builds/tests green and, on a real `~/.kangent` install, migrates and
serves against `~/.kamacu`.
</objective>

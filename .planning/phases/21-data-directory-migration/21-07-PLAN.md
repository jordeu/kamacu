RESEARCH-OQ3 copied-HOME recipe (`cp -a ~/.kangent $TMPHOME/.kangent; HOME=$TMPHOME ./bin/kamacu`) rewrote

the copy. Then re-run the automated smoke (app serves + boot-2 no-op) with the 21-06 fix present (so the real
install's 4 stale sched dirs no longer abort), assert the real-install manifest is byte-identical
before/after, and finally present the preserved 21-05 human-verify checkpoint.

the human sign-off that was blocked by the Gap-1 boot failure — the MIGRATE-01..05 phase gate.

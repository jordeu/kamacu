<objective>
Close Gap 1 from 21-VERIFICATION.md: `migrate.Complete` aborts the whole migration when a single
DB-referenced worktree dir exists on disk but is NOT registered in the repo's `.git/worktrees/`.
`repairWorktrees` passes every `os.Stat`-existing `tasks.worktree_path` to one `git worktree repair`
call and treats any nonzero exit as fatal — so the real `sched` repo's 4 stale dirs
(`add-nvidia-gpu-support-to-the-aws-vm-bac-2`, `cluster-gc-force-deletes-an-actively-ref-28`, `pr-561-22`,
`vmscalingservice-stale-launching-reap-ra-18`) make git exit 1, `Complete` returns an error,
`deleteOldTmuxRows` never runs, and the app refuses to boot on every boot (D-04 RollForward keeps
failing too).

Fix: repair per-path and tolerate individual "not a valid worktree / does not reference a repository"
failures — log a terminal-visible `slog.Warn` and skip the straggler, never abort — so `Complete`
proceeds to `deleteOldTmuxRows` and the app boots. RESEARCH Pitfall 2 only covered *non-existent* paths
(os.Stat-filtered); this closes the *existing-but-unregistered* case it missed.

Purpose: unblock MIGRATE-01/02/03/05 on the real install (Gap 1 is the sole blocker for the app booting).
Output: a hardened `repairWorktrees` + a regression test reproducing the stale-unregistered abort.
</objective>

    Six-state matrix (each via `newTestService(t, credsJSON, handler)` helper — t.TempDir creds file + httptest.Server base URL):
    - State 1 — file absent: credsJSON="" (no file written) → Result.State "no_credentials", Windows nil, zero handler hits
    - State 2 — key absent: `{"mcpOAuth":{}}` → "no_credentials", zero handler hits
    - State 3 — locally expired: valid shape with expiresAt 1 (epoch-ms past) → "auth_expired", ZERO handler hits (never burns an upstream call on a guaranteed 401)
    - State 4 — 429: handler returns 429 with `Retry-After: 60` after one 200 → next Get serves the cached windows with Stale true; a Get before backoffUntil does not hit the handler again
    - State 5 — 5xx: one 200 then 503×3 → Gets 2 and 3 serve stale (Stale true, State "error"), Get 4 (third failure) drops windows → Windows nil, State "error"
    - State 6 — malformed: handler returns 200 with body "not json" → same failure path as 5xx
    - 401: handler 401 → State "auth_expired"; with prior cache → stale-served for 2 more failures, then dropped
    - Token change (QUOTA-08): 200-cached, then rewrite creds file with a DIFFERENT fake token → next Get drops the old cache, refetches, failures reset
    - Happy path: captured live JSON → State "ok", Stale false, 3 windows; the captured request has header `User-Agent: claude-code/test`, `anthropic-beta: oauth-2025-04-20`, `Authorization: Bearer sk-ant-oat01-xxx…`
    - TTL: two Gets within 60s → one handler hit; force=true past the 10s floor → second hit; force=true WITHIN the 10s floor → still one hit (floor binds attempts, not successes)
    - Recovery: "auth_expired" then creds file rewritten with valid expiry + handler 200 → next Get returns "ok" (no special casing, Pitfall 6 nuance)
  </behavior>

    ```go
    type Config struct {
        CredentialsPath string // default: filepath.Join(home, ".claude", ".credentials.json")
        BaseURL         string // default: "https://api.anthropic.com"
        UserAgent       string // if "" → probe via DetectVersion(ClaudeBin)

        baseURL   string
        userAgent string
        client    *http.Client // Timeout: 10 * time.Second
        now       func() time.Time // time.Now; override in tests

        // cache state (all guarded by mu)
        cached       []Window
        tokenFP      string    // hex sha256 of the token the cache was fetched with (QUOTA-08)
        fetchedAt    time.Time // zero until first success; drives 60s TTL and FetchedAt
        lastAttempt  time.Time // set on EVERY upstream attempt; drives the 10s hard floor
        backoffUntil time.Time // 429: now + max(Retry-After, 30s)
        failures     int       // consecutive; >= 3 ⇒ drop cached (QUOTA-06)
        lastErr      string    // "" | "auth_expired" | "error" — picks the dropped/stale state
        inflight     bool      // in-flight dedup
    }

    func (s *Service) Get(ctx context.Context, force bool) Result
    ```

    Get() algorithm — per call (each browser poll / manual refresh):
    1. `os.ReadFile(credsPath)` FRESH every call (claude rewrites the file constantly; token rotates ~8h — Pitfall 1). Decode via readCredentials; discard everything else immediately.
    2. errNoCredentials → return `Result{State: "no_credentials"}` — no upstream call ever (D-71).
    3. Token change check (QUOTA-08): hex(sha256(token)) != s.tokenFP → drop cached, reset failures/lastErr, clear fetchedAt, proceed.
    4. expiresAt before now → behave as 401 WITHOUT an upstream request: failures++, lastErr="auth_expired"; if cached held and failures<3 → serve stale (State "auth_expired", Stale true, Windows cached); at failures>=3 drop cached → `Result{State: "auth_expired"}`.
    5. Serve cache (State "ok"/lastErr-as-is, Stale false if last attempt succeeded) WITHOUT fetching when ANY of: (!force && now.Sub(fetchedAt) < 60s && cached != nil); now < backoffUntil; (force && now.Sub(lastAttempt) < 10s); inflight. The 10s floor binds lastAttempt (attempts), the 60s TTL binds fetchedAt (successes) — separate fields or a failing upstream gets hammered by the 60s poll (Pitfall 3).
    6. Otherwise fetch (set inflight, lastAttempt=now, release mu during the HTTP call, reacquire after): `GET {baseURL}/api/oauth/usage` with headers `Authorization: Bearer <token>`, `anthropic-beta: oauth-2025-04-20`, `Content-Type: application/json`, `User-Agent: {userAgent}`.
    7. 200 → normalizeWindows; on success: cached=windows, tokenFP=fp, fetchedAt=now, failures=0, lastErr="" → `Result{State: "ok", Stale: false, FetchedAt: &fetchedAt, Windows: cached}`.
    8. 401 → failures++, lastErr="auth_expired"; serve stale while cached && failures<3, else drop → State "auth_expired".
    9. 429 → backoffUntil = now + max(Retry-After seconds, 30s) (missing/unparseable header → 30s); failures++, lastErr="error"; serve stale / drop as above.
    10. 5xx / network error / normalizeWindows error → failures++, lastErr="error"; serve stale while cached && failures<3, else drop → State "error".

    Stale serving builds `Result{State: lastErr, Stale: true, FetchedAt: &fetchedAt, Windows: cached}`.

    Error/log discipline (Pitfall 4): build internal errors from status codes only (`fmt.Errorf("upstream status %d", resp.StatusCode)`); slog at most the status code and failure count — NEVER the token, NEVER the request, NEVER response bodies (truncate-and-discard).

When cfg.UserAgent != "", use it verbatim (test seam — tests pass "claude-code/test" and never spawn claude).

<objective>
Add the merged/closed reviews data source to the shared `*github.Service`: a new `GetMergedClosed` method with its own 5min-TTL per-repo cache (D-03/D-04), backed by a new `listCompletedReviews` gh runner that searches `reviewed-by:@me` merged+closed PRs (D-05), returning `ReviewDoneSummary` values (D-06). This is the load-bearing gh integration for Phase 10's reviews-done list (REVIEWS-01) and the per-repo graceful-degradation foundation (REVIEWS-04).

Purpose: Decouple the reviews-done fetch from the review-column hot path (5s poll, 60s TTL) so the activity page's occasional views don't multiply gh load on the column, while reusing the Service's demand-driven cache state machine.
Output: Extended `internal/github` package (`service.go` + `prlist.go` + tests) consumed by Plan 02's `GET /api/activity` handler.
</objective>

<objective>
Build the `GET /api/activity` endpoint: one combined handler that answers "which tasks were done, which reviews were completed (merged/closed), and what are the cycle/dwell stats" for any Global / Workspace:N / Project:N scope and a Week (7d) / Month (30d) window. It parses+validates scope/window, runs the tasks-done SQL (D-12), computes cycle/dwell/median stats in Go (D-10/D-11), aggregates merged/closed reviews concurrently across in-scope linked repos via Plan 01's GetMergedClosed (D-07/D-08), enforces the GATE 1 toggle (D-02), and always returns HTTP 200 with degradation riding in reviews.state (REVIEWS-04). Registered alongside PullRequestRoutes on the shared ghSvc.

Purpose: Deliver the data + API layer Phase 11's Activity page renders — one endpoint, one TanStack query, one loading state.
Output: `internal/api/activity.go` (+ tests) and the `serve.go` route wiring.
</objective>

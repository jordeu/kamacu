<objective>
Close the Phase 11 UAT blocker (Test 1 — "black page on /activity"): the Activity page blanks on a
fresh/empty Kamacu instance because Go nil slices marshal to JSON null, violating the wire contract
the frontend types as `ActivityTask[]` / `ReviewDoneSummary[]`. React's render then throws on
`for...of null` / `[...null]` and unmounts to a blank page.

This is a canonical contract fix (backend is the source of truth) plus defense-in-depth null guards
on the frontend, plus a regression test that asserts the wire contract at the JSON byte level
(`tasks:[]` / `prs:[]`, not the null shape) — a `len==0` check alone cannot catch a nil-slice
regression because `json.Unmarshal` accepts the null shape for a slice.

Purpose: Restore the Phase 11 ACT-01 truth ("User can open a dedicated top-level Activity page") on
empty instances so UAT Test 1 can proceed.
Output: Verified non-nil-slice contract on every backend path; null-tolerant frontend; regression
test locking the wire shape.
</objective>

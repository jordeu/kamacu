    `cmd/kangent/main.go` — add the SPA fallback (RESEARCH.md Pattern 1 verbatim), AFTER `api.Routes`:
    ```go
    dist, _ := fs.Sub(web.DistFS, "dist")
    fileServer := http.FileServerFS(dist)
    mux.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
        if strings.HasPrefix(r.URL.Path, "/api/") {
            http.NotFound(w, r)
            return
        }
        p := strings.TrimPrefix(path.Clean(r.URL.Path), "/")
        if p != "" {
            if f, err := dist.Open(p); err == nil {
                f.Close()
                fileServer.ServeHTTP(w, r) // hashed asset → cacheable
                return
            }
        }
        w.Header().Set("Cache-Control", "no-store")
        http.ServeFileFS(w, r, dist, "index.html") // deep links → SPA
    })
    ```
    Import `kangent/web`, `io/fs`, `path`, `strings`. The `/api/` exclusion is load-bearing (Pitfall 3): unknown API paths must 404, never serve HTML.

    test:

    dev-backend:

    dev-frontend:

    Create `scripts/smoke.sh` (bash, `set -euo pipefail`, executable). Flow:

    1. `make build` (or assume built; rebuild for safety).
    2. Workspace: `WORK=$(mktemp -d)`; create a throwaway git repo: `mkdir $WORK/repo && git -C $WORK/repo init -q`.
    3. Start `./bin/kangent --addr 127.0.0.1:7402 --db $WORK/k.db &`; wait for `/api/healthz` (curl retry loop, max ~5s). `trap` kills the server and removes $WORK on exit.
    4. Create project: POST /api/projects `{"repo_path":"$WORK/repo"}` → expect 201 and `"name":"repo"` (default-name rule). Capture project id via grep/sed or jq if available (prefer pure grep/sed — no jq dependency).
    5. Negative: POST /api/projects `{"repo_path":"/nonexistent-zzz"}` → expect 400.
    6. Create task: POST /api/projects/$PID/tasks `{"title":"smoke task","description":"# md"}` → 201, capture task id.
    7. Move it: POST /api/tasks/$TID/move `{"status":"in_review","after_id":null}` → 200.
    8. Edit it: PATCH /api/tasks/$TID `{"description":"updated"}` → 200.
    9. **Restart**: kill the server PID, wait, start a new instance on the same `--db`, wait for healthz.
    10. Assert persistence: GET /api/projects still lists the project; GET /api/tasks/$TID returns `"status":"in_review"` and `"description":"updated"`.
    11. SPA checks: GET / contains `<html`; GET /projects/$PID/tasks/$TID (deep link) contains `<html`; GET /api/nope returns HTTP 404.
    12. Echo `SMOKE OK` and exit 0; any failed assertion exits non-zero with a message naming the step.

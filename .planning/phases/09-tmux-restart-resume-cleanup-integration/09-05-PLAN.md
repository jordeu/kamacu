<objective>
Ship the Done-TTL session reaper (REAP-01, D-86/D-90/D-95/D-96):
- D-90: `move` stamps the entered status's `*_at` column (last-entry-wins). Entering Done sets `done_at`; the reaper keys on it. The other three (`todo_at`/`in_progress_at`/`in_review_at`) are banked for future stats.
- The reaper is the codebase's FIRST background goroutine: a ticker that, each tick, finds tasks with `status = 'done'` whose `done_at` is older than the configured TTL and calls `mgr.StopAllForTask(taskID)` — killing bash, tmux, AND agent sessions.
- D-91: TTL from `done_session_ttl` (09-02); `never`/`0`/empty disables. Leaving Done cancels (reaper gates on `status = 'done'`, so a task that left Done is never reaped regardless of `done_at`).
- D-95: silent — no notification/badge; the server logs each reap. D-96: the agent's PTY is killed but `claude_session_id` + transcript are kept, so the agent shows its normal resumable ghost (fully reversible). This is automatic: `StopAllForTask` -> `Stop()` kills the PTY and never touches `tasks.claude_session_id`.

The reaper NEVER touches worktrees (D-87).

Purpose: stop bash/tmux/agent sessions from accumulating forever on finished tasks, reclaiming resources without destroying conversations.
Output: timestamp-stamping in move, a new `internal/reaper` package with a ticker goroutine, and its startup wiring.
</objective>

    `func (r *Reaper) reapOnce(ctx context.Context)` — the per-tick body, the unit under test:
    1. Read the TTL: `raw, _ := settings.Get(r.db, settings.KeyDoneSessionTTL)`; `ttl, disabled, err := settings.ParseDoneSessionTTL(raw)`. If `disabled || err != nil` → return immediately (reaping off, D-91; on parse error degrade to off and slog.Warn once — a saved-validated value should never fail, but never crash the goroutine).
    2. Compute the cutoff: `cutoff := r.now().UTC().Add(-ttl).Format("2006-01-02T15:04:05.000Z")` — the same ISO form done_at is stored in, so a lexical `<` comparison in SQL is correct (ISO-8601 sorts chronologically).
    3. Query expired Done tasks: `SELECT id FROM tasks WHERE status = 'done' AND done_at IS NOT NULL AND done_at < ?` with `cutoff`. The `status = 'done'` gate is D-90's cancellation (a task that left Done is excluded); `done_at IS NOT NULL` guards the NULL case.
    4. For each id: skip if the task has no running sessions (`anyRunning := false; for _, info := range r.mgr.ListByTask(id) { if info.Status == session.StatusRunning { anyRunning = true; break } }`; if !anyRunning continue). Else `r.mgr.StopAllForTask(id)` and `slog.Info("reaped Done-TTL sessions", "task", id, "ttl", ttl)` (D-95 log each reap). StopAllForTask kills bash+tmux+agent PTYs and KEEPS claude_session_id/transcript (D-96 resumable ghost — automatic, no extra code).
    5. NEVER touch worktrees (D-87) — the reaper only calls StopAllForTask.

    `func (r *Reaper) Run(ctx context.Context)` — the goroutine entry: `ticker := time.NewTicker(r.tick); defer ticker.Stop();` loop `select { case <-ctx.Done(): return; case <-ticker.C: r.reapOnce(ctx) }`. (Optionally run one reapOnce immediately at start so a restart reaps long-Done tasks without waiting a full tick.)

    Keep all logging via log/slog (project convention, no logging lib).

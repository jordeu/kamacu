Task JSON gains (all nullable): `"branch": string|null, "worktree_path": string|null, "worktree_error": string|null`

| Endpoint | Request | Responses |
|---|---|---|
| POST /api/tasks/{id}/worktree | empty body | 200 task JSON (success: branch+path set, error null; failure: worktree_error set). 404 unknown task. Idempotent: already has worktree -> 200 task as-is |
| GET /api/tasks/{id}/worktree | — | 200 `{"branch":string,"path":string,"dirty_files":int,"running_sessions":int}`; 404 `{"error":"task has no worktree"}` |
| DELETE /api/tasks/{id}/worktree | `{"stop_sessions":bool,"force":bool}` (empty body = both false) | 204 on success; 409 `{"error":"sessions running"}`; 409 `{"error":"worktree has uncommitted changes"}`; 404 no worktree; 500 `{"error":"<git error>"}` |
| POST /api/sessions | `{"task_id":number}` optional (empty body = dev session) | 201 session Info (taskId set); 404 `{"error":"task not found"}`; 409 `{"error":"task has no worktree"}` |
| GET /api/sessions?task_id=N | — | 200 filtered Info list (includes exited); 400 on non-integer task_id |

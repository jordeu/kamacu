# Phase 17 — UI Design Contract

> Visual and interaction contract for the Hardening & E2E phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 17 ships NO new UI.** It is a verification-debt phase: one real-binary E2E harness (D-47..D-54), the sentinel-leak regression family (D-55..D-57), the managed-root interlock (D-58), the UAT walkthrough (D-59..D-61), and two carried-forward cleanup debts (D-62/D-63). The entire frontend edit surface is **one type-only edit pair** — D-62's `Agent.engine` union widening + TaskPage QuotaIndicator predicate — whose single user-visible delta is a visibility-rule FIX on an existing component. Everything else the phase touches in a browser it *observes*, byte-for-byte, through the Phase-16 UI (16-UAT already verified that UX live; 17-CONTEXT carry-forward: "Phase 17 does not re-verify Phase-16 UX; it closes lifecycle gates").
>
> This contract therefore does five things: (1) locks the D-62 delta precisely, (2) defines the expected-visual vocabulary the E2E observations and UAT rows assert against (SC1–SC5), (3) locks the 17-UAT.md walkthrough doc's copy rules (D-59/D-60), (4) settles D-12's default (text-only bar row stands, D-61), and (5) freezes everything else — no visual regression, existing tokens/components reused verbatim (phase_context continuity mandate).
>
> Every D-decision below is cited to `17-CONTEXT.md` / `17-RESEARCH.md`. Nothing locked there is re-asked.

## UAT Walkthrough Copy Contract (D-59 / D-60 — the one place new copy is authored this phase)

`17-UAT.md` mirrors the `16-UAT.md` shape exactly:

- **Doc shape:** frontmatter (`status`, `phase: 17-hardening-e2e`, `source`, `started`, `updated`); numbered `### N. Title (gate-ref)` sections; each carries a one-line `expected:` and a `result:` line; a Summary block (`total/passed/issues/pending/skipped/blocked`); a Gaps section.
- **Flows (content LOCKED by D-59, numbering/copy at executor discretion):** configure (folder root against the user-picked real repo) → agent → bash → reattach → stop; BOTH engines' same-conversation resume (D-53); the interlock sanity (SC3); the sentinel-leak visual sanity (SC4); the D-61 bar-row clarity check (below).
- **Quoting rule:** every string a human reads in the browser appears in backticks **verbatim** from the 16-UI-SPEC copy table (grep-able template-literal convention); paths and repo refs rendered as mono literals in the doc. Expected lines must be specific enough for an unambiguous pass/fail judgment (name the state, the label, the button — "looks fine" is not an expected line).
- **Safety-posture paragraph (MANDATORY, D-60 + 17-RESEARCH Pitfall 10):** names the concrete risk — a `--dangerously-skip-permissions` agent writing directly into the checkout the user picked (no worktree net, no diff tab, no gated cleanup) — and suggests, without requiring, a disposable clone for wary users. Not boilerplate; not a disclaimer paragraph nobody writes seriously.
- **No screenshots required** (16-UAT precedent is text-only); results recorded as pass/fail lines.

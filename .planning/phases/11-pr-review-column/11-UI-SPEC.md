# Phase 11 — UI Design Contract

> Visual and interaction contract for the PR Review column. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Governing principle:** this phase is a **presentational variant of the existing board** (`Board`/`Column`/`TaskCard`) and a **behavioral sibling of the quota indicator** (best-effort, degrade-don't-break, show-stale, visibility-paused poll). It introduces **zero new tokens, zero new colors, zero new npm deps**. Every value below is the value the existing app already uses — re-stated so the executor matches, not reinvents.

## Spacing Scale

The app's de-facto scale is Tailwind's 4px base; the board uses a tight subset. Declared values (all multiples of 4):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px (`gap-1`, `pb-1`) | dot↔text gaps inside the checks pill; tight footer gaps |
| sm | 8px (`gap-2`, `p-2`) | card title↔dot row gap, inter-card gap (card list `gap-2`), header element gap |
| md | 12px (`px-3`, `py-2`→8/12, `p-3`) | card horizontal padding (`px-3 py-2`), column list padding (`p-3`), header horizontal padding (`px-3`) |
| lg | 16px (`gap-4`) | inter-column gap in the board flex row (`gap-4`) — the Review column inherits this |

Exceptions:
- The checks dot is **8px** (`size-2`) and the status dot offset is **`mt-[6px]`** — both verbatim from `StatusDot`/`TaskCard`, a deliberate sub-4 optical nudge that already exists in the contract. Do not change.
- Refresh icon button uses `size-icon-sm` with a `size-3.5` (14px) glyph — verbatim from the quota footer refresh.
- Card list padding `p-3` = 12px (not on the 8-grid) — **this is the existing column value**; the Review column must match it exactly, not "correct" it.

> The Review column copies `Column`'s exact paddings/gaps so it lines up pixel-for-pixel beside Done. Spacing is **inherited, not chosen**.

## Typography

Two weights only (regular 400, medium/semibold 500–600 via `font-medium`), three sizes in play — all already used by the board. No new type.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Card title | 14px (`text-sm`) | `font-medium` (500) | default (~1.5), `line-clamp-2` | PR title (mirrors `CardRow` title span exactly) |
| Card meta | 12px (`text-xs`) | regular (400) | leading-none / default | "#1457 · @author · updated 2h ago" line, count badge, all degraded/empty copy |
| Column label | 12px (`text-xs`) | `font-medium` (500) | default | "REVIEW" header label — `uppercase tracking-wide text-muted-foreground` (verbatim from `Column` header) |

- Body line height: **default Tailwind (~1.5)** — matches the board; do not override.
- No heading/display tier — the board has none; the Review column is not a page section, it is a column.
- Numerals in the count badge and any age text use `tabular-nums` (quota precedent) only if a number could change width in place; the static count badge may omit it.

## Color

Dark-only. All colors come from the shadcn zinc/neutral ramp already declared in `web/src/index.css` (`.dark`), plus the three semantic status hues already used by `StatusDot`. **No new color is introduced.**

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` = `oklch(0.141 ...)` (near-black zinc-950) + column track `bg-[#101013]` | board background, Review column card-list track (verbatim from `Column`) |
| Secondary (30%) | `--card` = `oklch(0.21 ...)` (zinc-900) via `bg-card`; hover `bg-[#27272a]` (zinc-800); muted text `--muted-foreground` | PR card surface, card hover, all secondary/meta text, the "REVIEW" label, count badge |
| Accent (10%) | status hues — `bg-green-500`, `bg-red-500`, `bg-amber-400` | **reserved exclusively for the checks dot** (pass/fail/pending) and the degraded-state warning glyph (amber). Nothing else gets a hue. |
| Destructive | `--destructive` | **not used** — Phase 11 is a pure read path; no destructive actions. |

**Accent reserved for (explicit list):**
1. Checks dot — `bg-green-500` (pass), `bg-red-500` (fail), `bg-amber-400` (pending). Verbatim from `dotMeta` (working/exited-failed/waiting).
2. Degraded inline note — `TriangleAlert` glyph in `text-amber-400` (verbatim from the quota warning chip). Used for `auth_required` / `error` only.
3. Stale footer text — `text-amber-400` when serving stale data after a failed refresh (verbatim quota stale-footer treatment).

The ↗ external-link icon, the refresh icon, the count badge, and all structural text stay **muted/neutral** (`text-muted-foreground`) — never accent. Accent must read as "CI signal / something needs attention," never as decoration.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Column label | `Review` (rendered `uppercase` → "REVIEW", mirroring status column labels) |
| Primary CTA | **none.** Card body is inert (D-08, reserved for Phase 12). The only affordance is a small ↗ external-link icon → "Open on GitHub". `aria-label="Open PR #{number} on GitHub"`. |
| Manual refresh | icon-only `RefreshCw` button, `aria-label="Refresh pull requests"` (mirrors quota's `aria-label="Refresh quota"`). No visible label. |
| Empty state heading | `You're all caught up` (ROADMAP/CONTEXT canonical voice — D-12) |
| Empty state body | `No PRs are waiting for your review.` (muted `text-xs`, single line) |
| Loading (first fetch) | No text — a quiet inline affordance: 1–2 `Skeleton` card placeholders (`bg-card` height ≈ a one-line card) inside the column list. Never a centered spinner, never a blocking overlay. |
| Degraded — `no_gh` | `GitHub CLI not found.` + secondary line `Install gh to see review requests.` (muted; amber glyph). |
| Degraded — `auth_required` | `GitHub not connected.` + secondary line `Run \`gh auth login\` to see review requests.` (mirrors quota's "re-authenticate with \`claude\`" voice; amber glyph). |
| Degraded — `error` | `Couldn't reach GitHub.` + secondary line, when serving stale data: `Showing last known list · {age} old` (amber, mirrors quota stale footer); when no prior data: `Try refresh.` Refresh button stays available. |
| Degraded — `disabled` | render **nothing** — the column does not appear at all (handled by the render gate, see Interaction Contract). This state should not surface as copy. |
| Stale-data footer | `Updated {age} ago` (muted) on success; `error · {age} old` (amber) when stale after a failed refresh — both verbatim from the quota footer. |
| Card meta line | `#{number} · @{author} · updated {relativeTime}` — relative time via the quota `formatAgo` style ("2h", "3d"); use "updated Xh ago" phrasing per GHCOL-03. |
| Collapsed count badge | bare number (e.g. `3`); tooltip/`title`: `{n} PR{s} awaiting review`. When degraded with no data, show no badge (or `—`), never `0`-as-error. |
| Destructive confirmation | **not applicable** — no destructive actions in Phase 11. |

Voice: terse, lowercase-where-the-app-is, no exclamation beyond the canonical empty-state line. Match the quota indicator's quiet, factual tone. Never alarm the user about a soft dependency — degrade quietly.

## Component Contract (phase-specific layout — prescriptive)

> These are the genuinely-undecided visual specifics (CONTEXT "Claude's Discretion"). They are now **decided** and locked here.

### Review column shell
- Rendered as a **sibling of the status `Column`s, to the RIGHT of Done**, inside the existing board flex row (`flex … gap-4 overflow-x-auto px-6 pb-6` in `Board.tsx`). **Not** a `dnd-kit` droppable — no `useDroppable`, no `SortableContext` (PR cards are never dragged, D-13).
- Outer wrapper matches a status column: `flex min-h-0 min-w-[260px] flex-1 flex-col` (verbatim from `Column`) so width tracks the status columns 1:1 on a wide board and never collapses below **260px**. Do **not** give it a different width — visual parity with task columns is the requirement.
- Header: same shell as `Column`'s header — `flex items-baseline gap-2 px-3 pb-2` — containing, left-to-right:
  1. collapse chevron toggle (lucide `ChevronDown`/`ChevronRight`, `size-3.5`, `text-muted-foreground`, in a `ghost`/`icon-sm` button), `aria-expanded` reflecting state, `aria-label="Collapse review column"` / `"Expand review column"`.
  2. `REVIEW` label — `text-xs font-medium uppercase tracking-wide text-muted-foreground` (verbatim status-label class).
  3. count — `text-xs font-medium text-muted-foreground` (verbatim status-count class). Reflects current GitHub state (D-07).
  4. spacer (`flex-1` / `ml-auto`), then the manual refresh button (`RefreshCw`, `size-3.5`, `ghost`/`icon-sm`), `disabled` while a refresh is pending and spinning is optional (no spinner library — reuse the quota pattern of just `disabled`).
- Card-list container: `flex min-h-0 flex-1 flex-col gap-2 overflow-y-auto rounded-md bg-[#101013] p-3` (verbatim from `Column`, minus the `isOver` ring since it is not a droppable). Loading/empty/degraded states render **inside** this container, inline.

### Collapsed column
- Collapse state persisted in **`localStorage`, keyed per-project** (`kangent:review-collapsed:{projectId}`), **default expanded** (D-05/D-06).
- Collapsed visual: the column narrows to a **slim rail** — a fixed `w-10` (40px) vertical strip, NOT `flex-1` — so it reclaims board width for the kanban while staying visible.
  - The strip keeps the same card-list track look (`rounded-md bg-[#101013]`).
  - Content top-to-bottom: the expand chevron button at top, then a **vertical "REVIEW" label** (`text-xs uppercase tracking-wide text-muted-foreground`, rotated via `[writing-mode:vertical-rl] rotate-180` or `-rotate-90`), then the **count badge** beneath/above the label.
  - Count badge: a small pill — `rounded-full bg-card px-1.5 text-xs font-medium text-muted-foreground` (neutral, never accent), centered in the rail. Shows the current PR count; hidden (or `—`) when degraded with no data.
  - The whole rail is clickable to expand (in addition to the chevron), `role="button"`, `aria-label="Expand review column ({n} PRs)"`.

### PR card (presentational variant of `TaskCard`)
- Surface identical to a task card: `rounded-md border border-border bg-card px-3 py-2`. **No** `hover:bg-[#27272a]`, **no** `cursor-grab`, **no** click navigation on the body — the body is **inert** (D-08). (Hover affordance is reserved for Phase 12; in Phase 11 the card body shows no hover state.)
- Two-row layout:
  - **Row 1 (title row):** `flex gap-2` — `<span className="line-clamp-2 flex-1 text-sm font-medium">{title}</span>` (verbatim `CardRow` title), then on the right the **checks dot** (when present) at `mt-[6px]` (echoing the status-dot offset), then the **↗ external-link icon**.
    - Checks dot: reuse `StatusDot`'s exact markup — `size-2 rounded-full shrink-0` with `bg-green-500` (pass) / `bg-red-500` (fail) / `bg-amber-400` (pending). Wrap in a `Tooltip` (`pass` → "Checks passing", `fail` → "Checks failing", `pending` → "Checks running"). When rollup is `none`, **render nothing** — no dot, no reserved gutter, no layout shift (D-04; the dotless-card rule).
    - ↗ icon: lucide `ExternalLink` or `ArrowUpRight`, `size-3.5`, `text-muted-foreground hover:text-foreground`, in an `<a href={url} target="_blank" rel="noreferrer">` (or `ghost`/`icon-sm` button that opens `url`). `aria-label="Open PR #{number} on GitHub"`. This `<a>` is the **only** interactive element on the card; its click must not be intercepted by any (future) card-body handler. The dot/icon sit in a small right-aligned cluster so the title `flex-1` still owns all extra width.
  - **Row 2 (meta line):** `text-xs text-muted-foreground` — `#{number} · @{author} · updated {Xh} ago`. Single line, `truncate` if needed. Use `·` (middot) separators. No diffstat, no fork pill, no head→base (D-02 — deferred to GHCARD).
- Cards listed **most-recently-updated first** (`updatedAt` desc, D-14).

### States (GHCOL-05 — all inline, never modal, never blocking)
- **Loading (first fetch, `data === undefined`):** 1–2 `Skeleton` placeholders in the list; header count hidden or shown as `·`. No spinner, no overlay.
- **Empty (`state: ok`, zero PRs):** centered-in-list block — heading `You're all caught up` (`text-sm text-muted-foreground`), body `No PRs are waiting for your review.` (`text-xs text-muted-foreground`). Quiet; no illustration.
- **Degraded (`no_gh` / `auth_required` / `error`):** a single muted inline note inside the list: `TriangleAlert` (`size-3.5 text-amber-400`) + the copy from the table above, stacked or inline. Refresh button stays active. **Never** a modal, **never** blocks the board (mirrors quota's warning chip).
- **Stale (`stale: true`):** render whatever PRs are cached, plus the amber stale footer (`error · {age} old`) at the bottom of the list (quota precedent). The list still shows; the column never goes blank just because a refresh failed.

## Interaction Contract

- **Render gate:** the Review column renders **only when** `useSettings().github_integration === 'on'` **AND** the project has a non-null `github_repo` (Phase 10 OFF-cascade + link gate). When the gate is closed, the column is **absent** — the board is byte-for-byte pre-v1.3. The `disabled` degraded state therefore never reaches the UI as copy.
- **Poll:** `useQuery(['pull-requests', projectId])` with `refetchInterval: 60_000` + `refetchIntervalInBackground: false` (visibility-paused — GHCOL-04). Only the active/visible project's column polls (D-10/D-11). Verbatim shape of `useQuota`.
- **Manual refresh:** `useRefreshPullRequests(projectId)` hits `GET /api/projects/{id}/pull-requests?refresh=1` and writes back via `qc.setQueryData(['pull-requests', projectId], data)` (verbatim `useRefreshQuota`). Button `disabled` while pending.
- **Self-emptying:** when the user submits a review on GitHub, the PR leaves `user-review-requested:@me`; the next poll/refresh drops the card. Do **not** locally cache against this — let the server list be the truth (PITFALLS). A card disappearing is correct behavior, not a bug to hide.
- **Endpoint is always-200** with `{ state, stale, fetchedAt, prs }`; the frontend branches on `state`/`stale`, never on HTTP status (degrade-don't-break).
- **No drag, no drop, no move** — PR cards never enter To Do / In Progress / In Review / Done and never call `/move`.

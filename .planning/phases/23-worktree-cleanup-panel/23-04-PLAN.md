Query-hook analog (web/src/api/diffs.ts:52 useTaskDiff) — fetch-on-mount, NO refetchInterval:
```
export function useTaskDiff(taskId: number) {
  return useQuery<DiffResponse, ApiError>({
    queryKey: ["diff", taskId],
    queryFn: () => get<DiffResponse>(`/api/tasks/${taskId}/diff`),
  });
}
```

Mutation-hook analog (web/src/api/worktrees.ts:48 useCleanupWorktree) — invalidate on success:
```
export function useCleanupWorktree(taskId, projectId) {
  const queryClient = useQueryClient();
  return useMutation<void, ApiError, { stop_sessions: boolean; force: boolean }>({
    mutationFn: (body) => del(`/api/tasks/${taskId}/worktree`, body),
    onSuccess: () => { queryClient.invalidateQueries({ queryKey: ["task", taskId] }); ... },
  });
}
```

Backend endpoint contract this plan types against (defined by Wave 2 plan 23-02 — treat as fixed):
- `GET /api/worktrees` → `{ projects: [{ project_id, project_name, icon_letters, icon_color, worktrees: WorktreeRow[] }], counts: { total, orphaned } }`
- `POST /api/worktrees/remove` `{ repo, path, task_id, force, stop_sessions }` → `204` on removed, `200 { outcome: "blocked", path }` on D-01 block, `409 { error }` on a raced gate, `500 { error }` on real error
- `POST /api/worktrees/clean-eligible?dry_run=1` → preview `{ items: EligibleItem[] }`; `POST /api/worktrees/clean-eligible` → `{ removed: number, skipped: number, results: [...] }`
- `POST /api/worktrees/clear-pointer` `{ task_id }` → `204`
where a `WorktreeRow` carries: `repo`, `path`, `task_id` (0 for orphan), `classification` ("referenced"|"orphan"|"stale"), `association` ("Task: X" | "PR #n" | null), `pr_state` ("merged"|"closed"|"open"|null), `branch`, `dirty`, `unpushed` (number | null when base unresolved), `stash`, `blocked` (bool), `blocked_path` (string | null), `sessions` (number).

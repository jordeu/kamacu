## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-04 | Tampering | client-side letters normalization | mitigate | The client mirror (uppercase/strip/<=2) is UX only; the SERVER is the enforcer (validateIconLetters, Phase 18 D-10) — a bypassed/altered client cannot store an invalid monogram. Empty letters → server 400 surfaced inline. |
| T-19-05 | Tampering | icon_color from swatch grid | mitigate | The grid only ever sets `color` to a member of `PROJECT_PALETTE`; the server additionally enforces palette membership (validateIconColor, Phase 18 D-11), rejecting any off-palette value. No free-form input (ICON-FUT-03 deferred). |
| T-19-06 | Injection (XSS) | swatch aria-label / 400 error message | mitigate | aria-label is a constructed string attribute and the error renders as a React text child (sentenceCase) — React auto-escapes; no `dangerouslySetInnerHTML`. swatch `backgroundColor` is a PROJECT_PALETTE hex into an inline style only. |
| T-19-S | Spoofing | — | N/A | Local-only single-user app; no auth surface. |
| T-19-R | Repudiation | PATCH edit | accept | A non-destructive, reversible self-edit of the user's own project metadata on a local single-user app; no audit requirement. |
| T-19-I | Information Disclosure | — | N/A | No secrets; edits only project identity fields already on the client. |
| T-19-D | Denial of Service | — | N/A | One PATCH on explicit Save; no unbounded loop (grid iterates a fixed 9-element const). |
| T-19-E | Elevation of Privilege | — | N/A | Reuses the existing project-update path; no new authz. |
| T-19-SC | Tampering (supply chain) | npm installs | N/A | No new npm packages — `lucide-react` (Check) and `cn` are already present (UI-SPEC Registry Safety: no installs). Nothing to gate. |
</threat_model>

<objective>
Build the RENDERING layer for the Sharper Review Column on top of the wire fields
shipped by 16-01. Three visual changes, all in two files:

1. **CI icons (CHECK-01/02):** replace the colored CI dot in PRCard with a bare
   lucide glyph — green `Check` (pass), red `X` (fail), amber `Circle` (running).
   `none` renders nothing. This frees the colored-dot vocabulary for agent state.
2. **Agent dot + session border (SIGNL-01/02/03):** a PR card with a linked
   review session shows the reused `StatusDot`, and gets a left border — blue for
   "I have a session here," amber for "needs my input" (waiting). Both key on the
   SAME signal (the agent-status entry), so they appear together, in BOTH sections.
3. **Recently reviewed section (REVWD-01/03/04):** a "Recently reviewed"
   subheader + the `reviewed` PRCards rendered below the awaiting list, inside the
   same scroll area, quietly omitted when empty.

Purpose: Make the Review column convey two independent at-a-glance signals (your
agent's state + the PR's CI state) without confusing them, and stop losing
reviewed PRs from view until they merge or close.
Output: A PRCard with the locked card-row contract `[title]·[dot]·[CI icon]·[↗]`
and the session-border state matrix, plus a ReviewColumn rendering both sections.
This plan ends in a human-verify checkpoint (the visuals are the deliverable).
</objective>

<interfaces>
Backend wire contract this layer mirrors (from plans 01 + 02):
- `GET /api/workspaces` → `Workspace[]` where `Workspace = { id:number; name:string; is_default:boolean; created_at:string; updated_at:string }`.
- `POST /api/workspaces` `{name}` → `Workspace` (409 duplicate, 400 empty).
- `PATCH /api/workspaces/{id}` `{name}` → `Workspace`.
- `DELETE /api/workspaces/{id}` → 204 (409 when non-empty or default).
- `PATCH /api/projects/{id}` `{workspace_id}` → `Project` (transfer).
- `POST /api/projects` `{…, workspace_id?}` → `Project` (create in workspace; omit → Personal).

Frontend idioms to reuse:
- `useProjects()` query shape — `web/src/api/queries.ts:5-10` (queryKey `["projects"]`).

- `get/post/patch/del` + `ApiError` — `web/src/api/client.ts:37-67, 1-9`.
- localStorage-backed `useState` + persist-on-change idiom — `web/src/components/layout/AppLayout.tsx:8-21` (`kamacu.sidebar`).
- `kamacu.*` key convention — `web/src/lib/migrateStorage.ts:22-41`.

<objective>
Add the open-or-reattach endpoint that turns a PR card click into a review workspace: `POST /api/projects/{id}/pull-requests/{n}/review`. It find-or-creates a `source='github_pr'` task keyed by `project_id + pr_number` (reattach, GHREV-02), provisions a detached worktree via `worktree.CheckoutPR` (GHREV-01), stores `pr_base_ref` for the diff plan, and returns the task row PLUS the live `PRDetail` (so the header/body never drift from GitHub).

Provisioning is SYNCHRONOUS (mirror the existing task-create path) — the mutation resolves with a ready task. gh/worktree failures degrade to an error response; the toggle-off / unlinked-project gates short-circuit before any gh spawn (GHSET-02/03 posture, mirroring the existing GET handler).

Purpose: this is the backend half of "click a PR → open a review." It composes the 12-01 leaf verbs (CheckoutPR, ViewPR) with the 12-02 source plumbing into one idempotent endpoint the frontend (12-05) routes to.
Output: the review endpoint + its main.go wiring + a fake-runner test harness proving create, reattach, the gates, and degrade.
</objective>

<objective>
Replace the agent view's standalone Stop button (and the separate Insert-description button) with
a single ⋯ dropdown menu (REVMENU-01), and remove the connect-time auto-insert of the PR-review
seed so it fires only from a manual `Insert review prompt` menu item (REVMENU-02). Bash panes keep
their inline Stop button untouched.

Purpose: The milestone's intent is manual, user-triggered prompt insertion. Today the PR seed is
pasted automatically on agent connect (guarded by a module-scope `seededSessionIds` set); this
plan deletes that auto-paste and re-homes the same bracketed-paste mechanism behind an explicit
menu item, folding `Insert description` and `Stop` into the same ⋯ menu.

Output: An edited `TerminalPane.tsx` (new agent-only `headerMenu` prop that supersedes the Stop
button); an edited `AgentTab.tsx` (⋯ menu built from the task-actions pattern; `seededSessionIds`
+ connect-time seed paste deleted).
</objective>

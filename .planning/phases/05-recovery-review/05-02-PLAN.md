```jsonc
{

  "totals": { "files": 3, "additions": 120, "deletions": 8 },

      ]
    }
  ]

```

Verified command pipeline (research §Diff Plumbing, git 2.43.0 — copy these flags verbatim):
```
mb    := git -C <wt> merge-base <base> HEAD                              # exit 128 → error w/ stderr
stats := git -C <wt> -c core.quotePath=false diff --no-color --no-ext-diff --numstat -z <mb>
patch := git -C <wt> -c core.quotePath=false diff --no-color --no-ext-diff <mb>
untr  := git -C <wt> -c core.quotePath=false ls-files --others --exclude-standard -z
per untracked f: git -C <wt> -c core.quotePath=false diff --no-index --no-color --no-ext-diff /dev/null <f>
                 # EXIT 1 = SUCCESS-WITH-DIFF; 0 = identical (skip); >1 = real error
```

Verified output formats:
- numstat -z plain record: `added<TAB>deleted<TAB><path><NUL>`; rename: `added<TAB>deleted<TAB><NUL><old><NUL><new><NUL>` (EMPTY path then two NUL tokens); binary: `-<TAB>-<TAB><path>`
- Rename detection is ON by default (diff.renames since git 2.9): `similarity index` / `rename from` / `rename to` headers; 100% similarity → no hunks
- Patch tolerances required: `\ No newline at end of file` lines, mode-change-only sections (no hunks), `new file mode` / `deleted file mode` headers
- no-index untracked patch: `diff --git a/<f> b/<f>` + `new file mode` + `--- /dev/null` + `+++ b/<f>` + hunks

Existing gitRun pattern to mirror (internal/worktree/worktree.go — exec.CommandContext arg arrays, exit-0 success, stderr trimmed + "fatal: " stripped). internal/diff gets its OWN runner because it needs the no-index exit-code contract worktree's never will.

Existing handler conventions: writeError/writeJSON (internal/api/respond.go), pathID, loadTaskRepo-style single query joining tasks + projects.repo_path (internal/api/worktrees.go lines 37-47).

    New package internal/diff. In parse.go define the JSON-ready types (exact tags — the frontend contract):
    ```go
    type Diff struct {
        Base   string `json:"base"`
        Totals Totals `json:"totals"`
        Files  []File `json:"files"`
    }
    type Totals struct {
        Files     int `json:"files"`
        Additions int `json:"additions"`
        Deletions int `json:"deletions"`
    }
    type File struct {
        Path      string  `json:"path"`
        OldPath   *string `json:"oldPath"`
        Status    string  `json:"status"` // modified | new | deleted | renamed
        Binary    bool    `json:"binary"`
        Additions *int    `json:"additions"` // nil for binary
        Deletions *int    `json:"deletions"`
        Hunks     []Hunk  `json:"hunks"`
    }
    type Hunk struct {
        Header string `json:"header"`
        Lines  []Line `json:"lines"`
    }
    type Line struct {
        Kind string `json:"kind"` // context | add | del
        Text string `json:"text"`
    }
    ```
    Marshal Files as `[]File{}` (never null) and Hunks as `[]Hunk{}`.

    parseNumstatZ(out string) — tokenize on NUL FIRST, then split each record on TAB. When the path field after the second TAB is EMPTY, consume the next two NUL tokens as old/new (rename). `-` for added/deleted marks binary. Return ordered records {Added, Deleted int; Binary bool; Path, OldPath string}.

    parsePatch(out string) — split on lines starting with "diff --git" (line-anchored, never substring — diff content can contain the phrase mid-line only if not at line start with the exact prefix; split on "\ndiff --git " plus the leading section). Per section: detect `Binary files ... differ` → binary, no hunks; collect file headers (`new file mode`, `deleted file mode`, `similarity index`/`rename from <p>`/`rename to <p>`); take the path from the `+++ b/<path>` line (or `--- a/<path>` for deletions where +++ is /dev/null; for renames use rename from/to headers). Hunks start at `@@`; each subsequent line: prefix `+` → add, `-` → del, ` ` → context, `\` (No newline marker) → skip. Status derivation: rename headers → "renamed"; `new file mode` → "new"; `deleted file mode` → "deleted"; else "modified".

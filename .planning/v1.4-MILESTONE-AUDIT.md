## Definition of Done

> When GitHub integration is on, add a project by naming a GitHub repo — Kangent `gh repo clone`s and manages the checkout under `~/.kangent/repos/<owner>/<name>` on the default branch — with the folder path as the optional fallback (folder-only when GitHub is off). Task worktrees branch off the managed checkout (fresh-fetched); the managed clone is gated-removed on project delete; clone failures degrade-don't-break with no half-created project; existing folder-based projects are untouched.

All success-criteria sets achieved and verified in code, tests, and the approved human checkpoint.

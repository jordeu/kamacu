<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test harness → spawned server process | the test constructs the child env entirely; anything not scrubbed propagates into the SUT |
| spawned server → host tmux socket | server B's startup sweepOrphanTmux kills any kamacu-* session with no DB row on its socket — the user's real work if isolation fails |
| test → loopback network | the harness binds an allocated 127.0.0.1 port and drives plain HTTP |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-01 | Denial-of-Service (user data) | server-B startup sweepOrphanTmux on the shared tmux socket | high | mitigate | TMUX_TMPDIR sandbox in the spawned server env AND every harness-side probe (17-RESEARCH Pitfall 1, empirically verified); t.Cleanup KillServer on the sandbox socket so nothing outlives the test |
| T-17-02 | Tampering / Spoofing | harness server binding a non-loopback or colliding address | medium | mitigate | --addr 127.0.0.1:<port allocated via net.Listen 127.0.0.1:0> only; serve's ensureLoopback rejects wildcards anyway (serve.go:432-439) |
| T-17-03 | Denial-of-Service (host) | stray processes (server, tmux server, fake-claude) outliving the test | medium | mitigate | LIFO t.Cleanup: SIGTERM+Wait the server with a Kill deadline, KillServer the sandbox socket, sandbox in t.TempDir |
| T-17-04 | Information Disclosure | parent KAMACU_* env (incl. the HOOK_TOKEN secret) inherited by the spawned test server | low | mitigate | the harness filters KAMACU_SESSION_ID, KAMACU_HOOK_TOKEN and KAMACU_HOOK_BASE out of the child env (dishonest isolation otherwise; the full production fix is plan 17-03's D-63) |

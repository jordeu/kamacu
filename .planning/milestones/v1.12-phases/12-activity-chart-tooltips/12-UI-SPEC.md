# Phase 12 — UI Design Contract

> Visual and interaction contract for the Activity Chart & Stat Tooltips phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Grounding note:** This phase is a **frontend-only extension** of the Phase 11 Activity page. CONTEXT locks 11 decisions (D-01..D-11): the chart library (recharts via shadcn chart pattern), the chart's position/stacking/degrade behavior, the stat-strip tooltip treatment, and the per-entry absolute-time swap. Every token below is cited to a real in-repo source. The phase adds **exactly one** new npm dependency (`recharts`, via `shadcn add chart` — D-01/D-02), **exactly one** new shadcn primitive (`chart.tsx`), **exactly one** new hand-rolled formatter (`formatDateTime` in `lib/time.ts`), and **zero** new design-system tokens — the two chart segment hues are drawn from the existing `PROJECT_PALETTE` (the documented muted source of truth). Discretion items from CONTEXT §"the agent's Discretion" are pre-populated below with prescriptive defaults grounded in `palette.ts` / `index.css` / Phase 11 idioms; the planner/executor may refine within the stated bounds but must preserve the cited source-of-truth.

**Page column width:** `max-w-[640px]` — unchanged from Phase 11. The chart canvas fills this width via `ResponsiveContainer width="100%"`. Source: `ActivityPage.tsx:40`.

**Chart-internal spacing (recharts props, not Tailwind):** *[default — CONTEXT discretion "exact recharts composition"]*
- `barCategoryGap="30%"` — breathing room between day-bars (7 bars stay legible; 30 bars don't touch).
- `barGap={2}` — 2px between the tasks and reviews segments within one stacked bar.
- `<CartesianGrid vertical={false} stroke="var(--border)" strokeDasharray="3 3" />` — horizontal gridlines only, dashed, at the border token (white@10% alpha).
- `<XAxis tickLine={false} axisLine={false} tick={{ fill: "var(--muted-foreground)", fontSize: 11 }} />` and matching `<YAxis>` — no axis lines, muted tick labels, allowDecimals={false}.
- Chart container margins: `<ResponsiveContainer>` inside shadcn `ChartContainer` (which sets its own padding); no extra page-level margins.

**Exceptions:** none. All values are multiples of 4. The recharts numeric props (`barGap=2`, `fontSize=11`) are pixel values internal to the chart canvas, not design-system tokens — they are chart-rendering parameters tuned for the `max-w-[640px]` × `h-48` canvas.

**Why palette.ts and NOT the default `--chart-1..5` tokens:** the shadcn defaults (`--chart-1: oklch(0.488 0.243 264.376)` etc. in `index.css:108-112`) are too saturated for the v1.7 UAT-muted decision (CONTEXT D-04 explicitly forbids "bright Tailwind-600 hues"). `PROJECT_PALETTE` is the project's documented muted source (desaturated, each clears WCAG AA — `palette.ts:7-9`). The planner/executor may swap to other `PROJECT_PALETTE` members (e.g. `#9c6b4b` orange for reviews) IF a UAT pass shows insufficient distinction; the contract is "two distinguishable muted `PROJECT_PALETTE` hues," the specific indices are the recommended default. *[default — CONTEXT discretion "precise muted hex values"]*

**Chart loading skeleton** uses `Skeleton` (unchanged primitive) at `h-48 w-full` — same muted shimmer as Phase 11.

## Interaction Contract

| Behavior | Contract | Source |
|----------|----------|--------|
| **Chart mount** | `<ActivityChart>` mounts inside the existing `isLoading ? <Skeleton/> : <loaded>` branch — it shares the page's single loading state. No separate chart loading gate. | Phase 10 D-01; *[default]* |
| **Scope/window change** | Selecting scope / toggling window updates the existing `useActivity` query key → one refetch → chart rebuckets from the fresh `data`. No chart-local state, no chart-local fetch. | CONTEXT domain; Phase 11 interaction contract |
| **Bar hover** | Hovering a bar (or focusing via keyboard if recharts a11y is wired) shows the `ChartTooltip` with absolute date + per-series counts. Cursor highlight = `var(--accent)` at 40% opacity (muted). Zero-day stubs are also hoverable (they show `0 tasks · 0 reviews`). | D-06 |
| **Stat tooltip open** | Hover OR focus the `Info` icon → tooltip opens instantly (`delayDuration=0`). Mouse leave / blur → closes (radix default). Tooltip does NOT steal pointer (radix default — content is non-interactive). | `tooltip.tsx:9`; radix defaults |
| **Stat tooltip keyboard** | Tab reaches the `Info` `<button>`; Enter/Space are NOT needed (focus alone opens, per radix `Tooltip` default with `delayDuration=0`). Esc dismisses. The button has `aria-label="{label} metric explanation"`. | radix defaults; D-08 a11y |
| **Entry click** | Unchanged from Phase 11: tasks → internal `Link` to `/projects/:projectId/tasks/:taskId`; reviews → external `<a target="_blank" rel="noreferrer">`. Only the time string beside the entry changes; the click target is unchanged. | Phase 11 D-14/D-15 |
| **Chart degrade** | `reviews.state ∈ HARD_DEGRADE` → reviews segment = 0 per bar (automatic from empty `prs`); tasks segment renders normally; chart never hides. `partial` → reviews render normally. | D-07 |
| **Window resize** | `ResponsiveContainer` handles canvas width; `h-48` height is fixed. `@xterm/addon-fit`-style refit NOT needed (not a terminal). recharts recalculates bar widths on container resize. | recharts default |
| **No toasts** | Chart degrade silent; tooltips hover-only; no sonner. | Phase 26 convention |
| **a11y** | Chart: recharts bars are not natively focusable — provide an `aria-label` on `<ChartContainer>` (e.g. `aria-label="Daily activity chart, {N} days"`) and a visually-hidden data table OR an `sr-only` summary as a refinement. Stat tooltips: keyboard-reachable `Info` buttons (above). The muted palette maintains WCAG AA contrast (palette.ts:8). *[default — chart a11y refinement]* | v1.7 UAT; *[default]* |

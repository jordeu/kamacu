## Typography

The app declares **two weights only**: regular (400, Tailwind default) and medium (500, `font-medium`). No `font-semibold`/`font-bold` appears in the page shells. Body default is `text-sm` set on `<body>` (`index.css:128`).

| Role | Size | Weight | Line Height | Tailwind classes | Source |
|------|------|--------|-------------|------------------|--------|
| Body | 14px | 400 | ~1.43 (20px) | `text-sm` (default on `<body>`) | `index.css:128`; used everywhere |
| Label / caption | 12px | 400 | ~1.33 (16px) | `text-xs text-muted-foreground` | `SettingsPage.tsx:145`, `PRCard.tsx:179` |
| Section subheading | 12px | 500 | ~1.33 (16px) | `text-xs font-medium tracking-wide text-muted-foreground uppercase` | `SettingsPage.tsx:79,161,171,183,198` — **the locked section-heading idiom** |
| Page heading | 16px | 500 | 1.5 (24px) | `text-base font-medium` | `SettingsPage.tsx:143`, `BoardPage.tsx:53` |
| Mono (stat values, durations, `#N`) | 14px | 400 | default | `font-mono` (overrides family only; size inherits `text-sm`/`text-xs`) | `SettingsPage.tsx:27` (`withMono`), `PRCard.tsx:179` |

**Line-height rules:**
- Body line height: **1.5** is the `<body>` ratio at `text-base`; for `text-sm` body copy the effective ratio is ~1.43 (Tailwind default 20px/14px). Both are within the recommended 1.4–1.5 band.
- Heading line height: **1.5** (Tailwind `text-base` = 24px line for a 16px heading).

**This phase uses exactly four sizes (12 / 14 / 16 + mono) and two weights (400 / 500).** No display size, no semibold/bold. The StatsStrip `min · median · max` values render in `font-mono text-sm` (D-09); the "over N tasks" caption renders in `text-xs text-muted-foreground` (D-09, mirroring the SettingsPage help-copy idiom).

## Color

The app is a **monochrome zinc dark theme** — there is no saturated brand hue in the default palette. The `menuAccent: "subtle"` preset means accent is expressed through *surface elevation and inversion*, not through color. All values below are the **runtime `.dark` tokens** (the `:root` light tokens are unused — dark-only app).

| Role | Value (oklch) | CSS var / Tailwind | Usage |
|------|---------------|---------------------|-------|
| Dominant (60%) | `oklch(0.141 0.005 285.823)` | `--background` → `bg-background` | Page background — the `h-full overflow-y-auto p-4` shell sits on this |
| Secondary (30%) | `oklch(0.21 0.006 285.885)` | `--card` / `--sidebar` / `--popover` → `bg-card` / `bg-sidebar` / `bg-popover` | Sidebar, dropdown menus, (future) cards. **Activity lists are NOT cards** (D-08: stacked single column, no cards grid) — so secondary surface is used only by the sidebar + the scope dropdown's `DropdownMenuContent` |
| Accent (10%) — inversion | `oklch(0.92 0.004 286.32)` | `--primary` → `bg-primary text-primary-foreground` | **Reserved for the primary inverted CTA only.** Activity is a read-only dashboard with NO primary CTA, so this is **unused** in this phase (mirrors BoardPage where "New task" is the sole inverted element — Activity has no equivalent) |
| Accent (10%) — surface | `oklch(0.274 0.006 286.033)` | `--sidebar-accent` / `--accent` → `bg-sidebar-accent` / `bg-accent` | **Active/hover backgrounds**: the Activity sidebar entry when `location.pathname === "/activity"` (`ProjectSidebar.tsx:181-182` idiom); scope-dropdown trigger hover/open (`WorkspaceSwitcher.tsx:61`); `Tabs` segmented-control active pill (`tabs.tsx:66` `data-active:bg-background`) |

| Border | `oklch(1 0 0 / 10%)` | `--border` → `border-border` | Dividers (rare in this phase — lists use whitespace, not rules) |

**Accent reserved for (explicit list — never "all interactive elements"):**
1. The Activity sidebar entry's active/hover background (`bg-sidebar-accent` when on `/activity`) — D-01.
2. The scope-dropdown trigger's hover/open background (`bg-sidebar-accent`) — `WorkspaceSwitcher` idiom.
3. The Week/Month segmented control's active pill (`data-active:bg-background` via Tabs) — D-07.
4. The primary inverted CTA — **intentionally unused** this phase (no primary action).

**Not used as accent in this phase:** the amber "waiting" chip (`bg-amber-400/10 text-amber-400`, `ProjectSidebar.tsx:148`) is a sidebar-agent-status signal and does not appear on the Activity page. No new saturated color is introduced.

**Stats values use `font-mono`** (family change only) on the default foreground — no numeric color-coding (no green-for-fast / red-for-slow). D-11's em-dash `—` for `n===0` renders in `text-muted-foreground` to read as "no data" rather than a measured value.

The only buttons are the scope dropdown (a control, not a CTA), the Week/Month segmented control (a control), and the error-retry button. | D-08 (read-only rendering of Phase 10 data); BoardPage's "New task" is the inverted-CTA idiom Activity deliberately omits |

| **Section heading — stats** | `Statistics` (uppercase, `text-xs font-medium tracking-wide text-muted-foreground uppercase`) *[default]* | SettingsPage section-heading idiom (`:161` etc.) |

| **Project group subheading** | `{projectName}` — `text-xs font-medium text-muted-foreground` (NOT uppercase; the uppercase-tracking-wide treatment is reserved for the top-level section headings). *[default]* | D-13; distinguishes group label from section label |
| **Empty state — tasks-done (no tasks in window)** | `No tasks completed in this window.` — single muted line, `text-sm text-muted-foreground`, no icon, no CTA. *[default]* | D-11 tone ("no measured zero"); matches the app's terse muted-empty style (contrast: no hint per D-12's spirit) |
| **Empty state — reviews-done (hard-degrade: gh off/absent/unauth)** | **Render NOTHING** — no heading, no body, no hint. The entire reviews section is suppressed (D-12 + RESEARCH Open Q1). | D-12 ("quietly empty — no error, no hint"); ACT-04; REVIEWS-04 |
| **Empty state — reviews-done (`ok`/`partial` but `prs.length === 0`)** | Suppress the section (heading + body) OR render just the heading with no entries — agent picks the quieter option. No "no reviews" hint copy. *[default]* | D-12 spirit; RESEARCH Open Q1 / Assumption A5 |
| **Error state (transport)** | `Couldn't load activity.` (`text-muted-foreground`) + a `Retry loading` button (`Button variant="outline"`). The endpoint is always HTTP 200, so this is purely transport-level (network down, server dead). | `SettingsPage.tsx:131-137`; Phase 10 D-02 (always 200) |
| **Destructive confirmation** | **None.** Activity has zero destructive actions — no delete, no edit, no clear. Only navigation (internal `Link`) and one external link (GitHub PR, `target="_blank" rel="noreferrer"`). | Out of Scope (REQUIREMENTS.md); D-14/D-15 |

**Copywriting conventions (locked):**
- **No toasts / no sonner** — all feedback is inline, muted, or in a dialog. The reviews degrade MUST NOT toast. (Phase 26 convention, restated in CONTEXT canonical_refs.)
- **Backtick/template-literal copy** — UI strings are written as grep-able template literals (e.g. `` `Activity` ``, not `"Activity"`), matching the `SettingsPage.tsx` convention. (Process convention; the checker greps source.)
- **`font-mono` for tokens** — any literal flag/param/example (`<n>`, `{slug}`, `week`, `#42`) renders in `font-mono` via the `withMono` helper pattern (`SettingsPage.tsx:18-38`). The Activity page has few such tokens (scope/window values are internal), but `#N` PR numbers and `min · median · max` durations use `font-mono`.

## Interaction Contract

Beyond the visual tokens, these interaction behaviors are locked:

| Behavior | Contract | Source |
|----------|----------|--------|
| **Route** | `/activity` — bare top-level route under `<AppLayout />`, sibling of `/settings`. No path params (scope/window are localStorage, never URL). | CONTEXT discretion; `App.tsx:135` pattern; D-06 |
| **Sidebar entry active state** | Derived from `location.pathname === "/activity"` (the Settings-gear idiom) — no router context probe. | `ProjectSidebar.tsx:181`; D-01 |
| **Sidebar entry reachability** | Visible in BOTH expanded footer and collapsed icon rail (D-02). Implementation: lift the entry out of the footer's `group-data-[collapsible=icon]:hidden` wrapper, OR apply the dual-surface classes. The *behavior* is locked; the DOM structure is agent discretion. | D-02; Pitfall 1 |
| **Scope change** | Selecting a scope item writes `kamacu.activity.scope` and updates the `useActivity` query key → one refetch, one loading state. No navigation (the route stays `/activity`). | D-04, D-06; Phase 10 D-01 |
| **Window change** | Toggling Week/Month writes `kamacu.activity.window` and updates the query key → one refetch. | D-07; Phase 10 D-01 |
| **Default scope on first open** | The active workspace (`useActiveWorkspace()`); falls back to `global` while unresolved. The query is `enabled` only once scope resolves to a valid grammar string. | D-05; Pitfall 6 |
| **Persistence on reload** | Reload restores the last scope + window from localStorage. Stale/invalid saved scope → default (active workspace); stale window → `week`. | D-06 |
| **Tasks-done click** | Internal navigation: `Link`/`navigate` to `/projects/:projectId/tasks/:taskId`. `activityTask` carries both `id` and `projectId` — no lookup. | D-15; TASKS-03 |
| **Reviews-done click** | External link: `<a href={url} target="_blank" rel="noreferrer">` opening the GitHub PR. NOT `window.open` (popup-blockable). NOT a `<Link>` (external URL). Conscious universal-PR-URL choice — **flag at UAT** (D-14 deliberate simplification). | D-14; `PRCard.tsx:166`; Pitfall 7 |
| **Reviews degrade** | Branch on `reviews.state`: hard-degrade set `{ disabled, no_gh, auth_required }` with empty `prs` → suppress entire section (no heading, no hint). `ok`/`partial`/`error` → render whatever `prs` contains, grouped. **Never whitelist `{ ok }` alone** — `partial` carries real PRs. | D-12; Pitfall 2; ACT-04/REVIEWS-04 |
| **Reviews ordering** | Client-side sort `prs` by `completedAt DESC` before/within grouping (cross-repo merge is unsorted server-side). Tasks arrive already `doneAt DESC` from SQL — do not re-sort. | D-13; Pitfall 5 |
| **Stat `n===0`** | Render em-dash `—` (in `text-muted-foreground`) for the whole `min · median · max` cluster; counts render literal `0`. Never `0m`/`0s`. | D-11; Pitfall 4 |
| **Stat values are SECONDS** | `timeStat.min/max/median` are `int64` seconds (truncated). `formatDuration` treats its input as seconds. Never format as ms. | D-10; Pitfall 3; `activity_helpers.go:100-102` |
| **Refetch behavior** | No `refetchInterval` (Activity is an occasional view, not a live dashboard). Default TanStack `refetchOnMount` — a fresh fetch on each open is correct and cheap (5min gh cache on the backend absorbs repeats). | RESEARCH Open Q3 recommendation; Phase 10 merged-closed cache TTL |
| **Keyboard / a11y** | All controls are radix primitives → standard keyboard/ARIA. Scope dropdown trigger has `aria-label="Scope: {name}"`; review external link has `aria-label="Open PR #{number} on GitHub"`; sidebar entry has `aria-label="Activity"`. | radix-ui defaults; `PRCard.tsx:170`; `WorkspaceSwitcher.tsx:60` |
| **No toasts** | All feedback inline/muted/dialog. The reviews degrade is silent. | Phase 26 convention; D-12 |

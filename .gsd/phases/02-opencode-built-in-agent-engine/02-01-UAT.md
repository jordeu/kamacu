## Automated runtime checks (this slice's scope)

### UAT-01 — opencode is a non-deletable system agent seed
- Steps: `go test ./internal/store/ -run Opencode -count=1`; `SELECT name,engine,command,is_default,is_system FROM agents WHERE engine='opencode'` after a fresh migrate.
- Expected: tests pass; exactly one opencode row, `engine='opencode'`, `command='opencode'`, `is_default=0`, `is_system=1`; claude remains the sole `is_default=1` (R019); idempotent across restarts (BackfillOpenCodeAgent no-ops).
- Edge: dropping the seed then rebooting re-creates it; `is_system=1` blocks deletion at the API (R018).

### UAT-02 — opencode spawn injects the KAMACU_* hook env (engine-gated)
- Steps: `go test ./internal/session/ -run Opencode -count=1`.
- Expected: `TestOpencodeSpawnInjectsHookEnv` asserts `KAMACU_SESSION_ID==s.Info().ID`, `KAMACU_HOOK_TOKEN`, `KAMACU_HOOK_BASE` present for an opencode-engine child; `TestCustomEngineDoesNotGetHookEnv` asserts all three ABSENT for a custom-engine child (R017 byte-for-byte guard); `TestOpencodeEngineKeepsHeuristicStates` asserts status ∈ {working,idle,waiting}, never `running`.

### UAT-03 — env-gated plugin installs idempotently, no-pollution, content-correct
- Steps: `go test ./internal/opencode/ -count=1`.
- Expected: 7 cases pass — no-op when `~/.config/opencode` absent (no-pollution), no-op when target is a file, writes when dir present, skip-on-match idempotent, overwrites stale, content carries the `kamacu-managed` header + the three env vars + claude event names (SessionStart/Notification/Stop) + `X-Kangent-Token` + singular `plugin/` path + singleton guard + parentID child-suppression.

### UAT-04 — UNCHANGED hook receiver drives opencode working/waiting/idle + hooksAlive canary
- Steps: `go test ./internal/api/ -run OpencodeHook -count=1`.
- Expected: 5 cases pass — heuristic states (never `running`), Notification→waiting, Stop→idle, SessionStart→hooksAlive (BEL fallback disabled, with a hooks-dead control), and the full one-turn loop (SessionStart→Notification→Stop). hooks.go is unmodified.

### UAT-05 — regression: claude and custom engines unchanged
- Steps: `go test ./internal/session/ -run 'Custom|Claude' -count=1`; `go test ./internal/api/ -run Hook -count=1`.
- Expected: fake-claude suite (R016) and custom-engine suite (R017) pass unchanged; the engine-agnostic hook boundary suite passes.

## Deferred LIVE opencode UAT (milestone gate, human-follow-up)

- Preconditions: opencode CLI installed; `~/.config/opencode/` present; kamacu running.
- Steps: create a project whose agent is opencode; create a task; open the task Agent tab; trigger a permission prompt and a turn end.
- Expected: opencode launches in the terminal; status dot transitions working→waiting (permission.ask)→idle (turn end) in the browser; `hooksAlive=true` after the first SessionStart; the managed plugin file exists at `~/.config/opencode/plugin/kamacu-status.js`.
- Non-automatable because: requires the real opencode binary not present in CI.

# S02: Gated status plugin unlocks waiting and idle

**Goal:** Retire the plugin-half risk S01 deferred: prove the shipped opencode status plugin loads in real opencode and its hook POSTs reach the unchanged receiver to unlock waiting/idle. Fix the load-bearing defect (notify() shells out to curl via Bun $, which silently no-ops on hosts without curl on PATH so hooksAlive never flips and waiting/idle never unlock) by switching to global fetch() + a 3s AbortController exactly as D014/T03-PLAN specified, and add the first real-binary opencode end-to-end proof.
**Demo:** After this: an opencode permission prompt flips the task status to waiting; turn end flips it to idle — same UX as claude.

## Must-Haves

- notify() in internal/opencode/kamacu-status.js uses global fetch() with a 3s AbortController (method POST, X-Kangent-Token + Content-Type headers, body=payload); it no longer shells out to curl via Bun $. assertPluginContent pins `fetch` + `AbortController` present and asserts `curl` is ABSENT from the plugin source (regression guard so the silent-no-op-on-curl-missing defect cannot return).
- A //go:build opencode_e2e integration test (internal/opencode/e2e_test.go) spawns real `opencode run` with the managed fetch-based plugin (PluginSource() bytes) installed into an isolated temp XDG_CONFIG_HOME and KAMACU_* env pointing at a self-contained httptest receiver; it t.Skip's cleanly when `opencode` is not on PATH or no provider config exists.
- The e2e real-turn case asserts the receiver observes at least a Stop (idle) POST from a real opencode 1.17.15 turn (the plugin->receiver loop proven end-to-end); the env-gate case asserts ZERO receiver POSTs when KAMACU_SESSION_ID is unset (gate proven against the real binary).
- Receiver and env-injection regression suites stay green with hooks.go, session.go, and manager.go code unchanged (TestCustomEngineDoesNotGetHookEnv + the opencode-hook api suite are the negative guards).

## Proof Level

The LIVE browser status-dot transition (working->waiting->idle) remains the human milestone UAT gate.
